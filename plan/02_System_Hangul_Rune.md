# [기획서] 02. 한글 룬 시스템 (Hangul Rune System) - 상세 알고리즘

## 1. 한글 속성 조합 알고리즘 (Attribute Mapping)
수천 개의 한글 조합을 관리하기 위해, 자음/모음의 위치(초/중/종성)에 따라 고유한 **'속성 가중치'**를 부여합니다.

### 1.1. 초성 (Initial): 공격 형태 및 물리 속성
| 초성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **ㄱ, ㅋ** | 날카로움 (Sharp) | 치명타 확률 +3% |
| **ㄴ, ㄹ** | 유연함 (Flexible) | 공격 속도 +5% |
| **ㄷ, ㅌ** | 묵직함 (Heavy) | 물리 데미지 +7% |
| **ㅂ, ㅍ** | 파괴적 (Destructive) | 방어구 관통 +5% |
| **ㅅ, ㅎ** | 신성/정신 (Holy) | 마나 재생 +10% |
| **ㅇ** | 순수 (Pure) | 모든 스탯 +2 |

### 1.2. 중성 (Medial): 원소 속성 (Elemental)
| 중성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **ㅏ, ㅑ** | 화염 (Fire) | 화염 데미지 +5 |
| **ㅓ, ㅕ** | 대지 (Earth) | 최대 체력 +50 |
| **ㅗ, ㅛ** | 빛 (Light) | 시야 범위 +2 |
| **ㅜ, ㅠ** | 냉기 (Cold) | 적 이동속도 저하 (1%) |
| **ㅡ, ㅣ** | 바람 (Wind) | 이동 속도 +3% |

### 1.3. 종성 (Final): 부가 효과 및 상태 이상
| 종성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **(없음)** | 순수함 | 기본 속성 1.2배 증폭 |
| **ㄱ, ㄴ** | 견고함 | 방어력 +10 |
| **ㄹ, ㅁ** | 흡수 | 타격 시 체력 흡수 0.5% |
| **ㅇ, ㅎ** | 폭발/방출 | 광역 데미지 범위 +5% |

## 2. 완성룬(Glyph) 능력치 계산식
하나의 완성된 글자 룬의 최종 능력치는 다음 두 가지 규칙 중 하나를 따릅니다.

### 2.1. 기본 조합 (단순 합산)
특별한 의미를 갖지 않거나 일반적인 글자들의 경우, 자모음의 속성이 그대로 더해집니다.
- **예: '강' (ㄱ + ㅏ + ㅇ)**
    - **ㄱ (초성):** 치명타 확률 +3%
    - **ㅏ (중성):** 화염 데미지 +5
    - **ㅇ (종성):** 광역 데미지 범위 +5%
    - **최종:** [치명타 3%, 화염 5, 광역 5%] 옵션을 가진 룬

### 2.2. 의미 발현 (Semantic Override) - 예외 규칙
조합된 글자가 실제 자연계의 원소나 강력한 순우리말(예: 불, 물, 빛, 땅)일 경우, 단순한 자모음 합산을 초월하는 **'고유 속성(Override)'**이 부여됩니다.
- **예: '불' (ㅂ + ㅜ + ㄹ)**
    - 공식대로라면 '관통(ㅂ) + 냉기(ㅜ) + 흡수(ㄹ)'가 되어야 하지만, 조합이 완성되는 순간 **태초의 의미인 '불(Fire)'이 발현**됩니다.
    - **결과:** 기존 자모음의 물리적 속성이 불태워지고, **[강력한 화염 데미지, 화상, 폭발]**이라는 고유 스탯으로 완전히 대체됩니다.
    - 이 예외 규칙 덕분에 특정 글자들은 기계적 조합 공식을 무시하고 압도적인 가치를 지니게 됩니다.

## 3. 한글 조합 확률 및 파괴 시스템 (Crafting & Breakage)
자음과 모음 파편을 결합하여 완성룬을 만드는 과정은 100% 성공하지 않으며, 글자의 태생적 근본(어원)에 따라 난이도가 극명하게 갈립니다.

### 3.1. 어원에 따른 등급 및 조합 성공률 (5% ~ 70%)
- **한자어 룬 (하위~중위 등급):** 
  - 예: 월(月), 화(火), 수(水), 천(天), 지(地) 등.
  - 태생적으로 외부에서 유입된 개념이므로 룬의 마력이 상대적으로 안정적입니다.
  - **조합 성공률:** 40% ~ 70% (비교적 만들기 쉬움)
- **순우리말 룬 (상위~최상위 등급):**
  - 예: 불, 물, 흙, 땅, 빛, 별 등.
  - 태초의 말씀과 가장 맞닿아 있는 순수한 형태이므로 마력의 반발력이 극도로 심합니다.
  - **조합 성공률:** 5% ~ 20% (만들기 매우 어려우나, 파티 던전 보스를 통해 완제품 파밍 가능)

### 3.2. 실패 시 패널티 (Breakage)
조합에 실패하면 룬의 마나가 폭주하여 재료가 손상됩니다.
- **파괴 (Destroyed):** 조합에 사용된 파편 중 1~2개가 '깨진 룬 가루'로 변하며 영구 소실됩니다.
- **안전 장치:** 거래소나 퀘스트를 통해 얻은 '장인의 잉크'를 조합에 첨가하면 실패 시 파편 소실을 막아줍니다.

## 4. 천지인 각성 시스템 (Primal Awakening)
게임 후반부(기원의 땅)에서 획득하는 고대 모음 **천지인(•, ㅡ, ㅣ)**은 일반적인 글자 조합에 사용되지 않고, 이미 완성된 글자 룬(Glyph)을 한 차원 높게 **'각성'**시키는 재료로 쓰입니다.

### 4.1. 각성 로직
- **공식:** `[완성룬(예: 강)]` + `[천지인 파편(예: •)]` = **`[각성된 강]`**
- **효과:** 각성된 룬은 기존 스탯이 2배~3배로 뻥튀기되며, 아이템에 장착 시 기존의 유광을 넘어선 **'나전칠기(자개) 광택'**을 뿜어냅니다.

### 4.2. 천지인 속성 부여
- **• (천/하늘):** 신성, 범위, 정신적 스탯 폭발.
- **ㅡ (지/땅):** 방어, 체력, 물리적 내성 극대화.
- **ㅣ (인/사람):** 공격 속도, 치명타, 회피 등 기교 스탯 극대화.

## 5. 단어 룬 융합: 의미 부여 시스템 (Word Rune Crafting)
장비의 소켓에 글자를 하나씩 박는 대신, 인벤토리(조합창)에서 여러 글자를 융합하여 완전히 새로운 **'단어 룬(Word Rune)' 아이템**을 창조합니다.

### 5.1. 의미 부여 로직 (Manifestation)
- **방식:** 인벤토리에 있는 완성룬(예: '태', '양')을 조합창에 올리고 '의미 부여'를 실행하면, 두 룬이 융합되어 **[태양]**이라는 하나의 단일 아이템(단어 룬)이 탄생합니다.
- **결과물:** 이렇게 완성된 단어 룬은 거래가 가능하며, 강력한 고유 스탯과 특수 발동(Proc) 이펙트를 지닙니다.

### 5.2. 단어 룬 옵션 예시 (예: '태양')
- **조합 재료:** [태] + [양]
- **기본 스탯:** 모든 스탯 +1, 화염 저항 +20%
- **의미 발현 스탯:** 화염 공격력 +50 (제작 시 5~10% 랜덤 보너스 부여)
- **특수 발동 이펙트:** 무기에 장착 시 공격 중 확률적으로 하늘에서 작은 운석이 떨어지며 몬스터를 불태움 (태양의 힘).

### 5.3. 글자 수 기반 등급 (Word Length)
- **1글자 (자연계):** 불, 물, 땅 (의미 발현으로 단일 룬 중 최상위 위력)
- **2글자:** 태양, 바람, 강화 (특정 액티브 이펙트 발동)
- **3~4글자:** 미리내, 천지창조 (극악의 제작 난이도, 화면 전체 광역 판정 등 궁극기급 발동)
