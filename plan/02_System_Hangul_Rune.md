# [기획서] 02. 한글 결 시스템 (Hangul Core System)

## 1. 핵심 원칙
- **조합**은 자모 파편을 이용해 글자결을 만드는 단계다.
- **각인**은 글자결을 이용해 진언결/언령결을 만드는 단계다.
- 인벤토리 1칸을 차지하는 완성형 결과물의 총칭은 **결**이다.
- 각인에 필요한 필수 재료의 총칭은 **돌**이다.
- 실패 완화용 보조 재료의 총칭은 **먹**이다.

## 2. 자모 속성 매핑

### 2.1. 초성: 물리/형태 속성
| 초성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **ㄱ, ㅋ** | 날카로움 | 치명타 확률 +3% |
| **ㄴ, ㄹ** | 유연함 | 공격 속도 +5% |
| **ㄷ, ㅌ** | 묵직함 | 물리 데미지 +7% |
| **ㅂ, ㅍ** | 파괴성 | 방어구 관통 +5% |
| **ㅅ, ㅎ** | 신성/정신 | 마나 재생 +10% |
| **ㅇ** | 순수 | 모든 스탯 +2 |

### 2.2. 중성: 원소 속성
| 중성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **ㅏ, ㅑ** | 화염 | 화염 데미지 +5 |
| **ㅓ, ㅕ** | 대지 | 최대 체력 +50 |
| **ㅗ, ㅛ** | 빛 | 시야 범위 +2 |
| **ㅜ, ㅠ** | 냉기 | 적 이동속도 저하 |
| **ㅡ, ㅣ** | 바람 | 이동 속도 +3% |

### 2.3. 종성: 보조 속성
| 종성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **없음** | 순수함 | 기본 속성 1.2배 증폭 |
| **ㄱ, ㄴ** | 견고함 | 방어력 +10 |
| **ㄹ, ㅁ** | 흡수 | 타격 시 체력 흡수 |
| **ㅇ, ㅎ** | 방출 | 광역 범위 증가 |

## 3. 글자결 생성

### 3.1. 규칙 기반 조합
- 자음/모음 파편을 조합해 유효한 한글을 만들면 **글자결**이 생성된다.
- 예: `ㄱ + ㅏ + ㅇ -> 결: 강`

### 3.2. 글자결의 역할
- 장비에 직접 장착 가능한 기초 결
- 상위 진언결/언령결 제작의 재료
- 일부 희귀 글자결은 단독으로도 강한 가치 보유

### 3.3. 조합 확률
- 조합은 100% 성공이 아니다.
- 다만 초반 글자결은 지나치게 가혹하지 않도록 높은 성공률을 유지한다.
- 희귀 글자결일수록 낮은 성공률과 높은 제작 리스크를 갖는다.

## 4. 진언결 각인

### 4.1. 정의
- 여러 글자결을 모아 정해진 단어를 만들고, **돌: 새김** 계열 촉매를 사용해 패시브형 **진언결**로 각인한다.

### 4.2. 원칙
- 진언결은 자유 생성형이 아니라, 미리 정의된 단어만 결과물로 인정한다.
- 티어별 진언결 수량은 약 5개 내외로 제한한다.

### 4.3. 예시
- `결: 태` + `결: 양` + `돌: 새김` -> `결: 태양`
- `결: 강` + `결: 화` + `돌: 새김` -> `결: 강화`

## 5. 언령결 각인

### 5.1. 정의
- 여러 글자결을 모아 정해진 문장을 만들고, **돌: 말문** 계열 촉매를 사용해 액티브형 **언령결**로 각인한다.

### 5.2. 원칙
- 언령결은 정해진 문장만 결과물로 인정한다.
- 티어당 속성별 1개를 기본 원칙으로 한다.
- 상위 티어 언령결은 같은 속성의 하위 티어 언령결과 연계된다.

### 5.3. 예시
- `결: 어` + `결: 둠` + `결: 을` + `결: 밝` ... + `돌: 말문` -> `결: 어둠을 밝히는 불꽃이여`

## 6. 보호/보정 재료

### 6.1. 먹 계열
- `먹: 지킴` = 실패 시 핵심 재료 보존
- `먹: 남김` = 실패 손실 완화
- `먹: 돋움` = 각인 성공률 소폭 증가

### 6.2. 적용 구간
- `씨앗 ~ 무늬`: 거의 사용하지 않음
- `물결 ~ 울림`: `먹: 남김` 중심
- `숨결 ~ 온결`: `먹: 지킴`, `먹: 남김`, `먹: 돋움`이 모두 중요

## 7. 천지인 각성
- 후반 `근원의 나라`에서 획득하는 `천지인`은 새 언령결을 만드는 재료가 아니다.
- 대신 이미 보유한 낮은 티어 언령결을 강화하는 각성 재료다.
- 강화 시 성능, 범위, 상태 이상, 연출이 함께 상승한다.
