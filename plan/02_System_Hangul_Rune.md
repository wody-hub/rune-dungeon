# [기획서] 02. 한글 결 시스템 (Hangul Core System)

## 1. 핵심 원칙
- **조합**은 `음`을 이용해 **자형**을 만드는 단계다.
- **각인**은 **자형**에 의미를 새겨 **결**로 완성하는 단계다.
- 인벤토리 1칸을 차지하는 완성형 결과물의 총칭은 **결**이다.
- 각인에 필요한 필수 재료의 총칭은 **돌**이다.
- 실패 완화용 보조 재료의 총칭은 **먹**이다.

## 2. 자모 속성 매핑

### 2.0. 매핑 테이블의 지위
- 아래 자모 속성 매핑은 자형·결의 이름, 속성 계열, 효과 방향을 정할 때 참고하는 `설계 지침`이다.
- 개별 자형·결의 실제 능력치는 `plan/09_Data_Sheet_Runes.md`와 `data/design/gyeol-balance.json`이 정본이며, 매핑에서 기계적으로 유도하지 않는다.
- 조합 글자는 구성 자모의 속성 전부를 합산하지 않고, 일부만 대표 효과로 채택할 수 있다. 예: `자형: 강`(ㄱ+ㅏ+ㅇ)은 ㄱ의 `날카로움`(치명타)을 대표 효과로 채택한다.
- 아래 표에 없는 복합 모음은 구성 모음의 속성을 함께 참고한다. 예: `ㅘ = ㅗ + ㅏ`는 빛·화염 계열을 함께 참고하며, `자형: 화`는 화염을 대표 속성으로 삼는다.

### 2.1. 초성: 물리/형태 속성
| 초성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **ㄱ, ㅋ** | 날카로움 | 치명타 확률 +1% |
| **ㄴ, ㄹ** | 유연함 | 공격 속도 +5% |
| **ㄷ, ㅌ** | 묵직함 | 데미지 % 증가 +7% |
| **ㅂ, ㅍ** | 결의힘 | 치명타 피해 +3% |
| **ㅅ, ㅎ** | 제압 | 스턴 확률 증가 +3% |
| **ㅇ** | 순수 | 모든 스탯 +2 |

### 2.2. 중성: 원소 속성
| 중성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **ㅏ, ㅑ** | 화염 | 속성 공격력 % 증가 +5% |
| **ㅓ, ㅕ** | 대지 | 데미지 % 증가 +5% |
| **ㅗ, ㅛ** | 빛 | 속성 공격력 % 증가 +3% |
| **ㅜ, ㅠ** | 냉기 | 받는 스턴 시간 감소 +5% |
| **ㅡ, ㅣ** | 바람 | 이동 속도 +3% |

### 2.3. 종성: 보조 속성
| 종성 | 속성 명칭 | 기본 효과 |
| :--- | :--- | :--- |
| **없음** | 순수함 | 기본 속성 1.2배 증폭 |
| **ㄱ, ㄴ** | 집중 | 치명타 피해 +3% |
| **ㄹ, ㅁ** | 가속 | 공격 속도 +3%, 이동 속도 +3% |
| **ㅇ, ㅎ** | 억제 | 받는 스턴 확률 감소 +5% |

## 3. 자형 생성

### 3.1. 규칙 기반 조합
- `음`을 조합해 유효한 한글을 만들면 **자형**이 생성된다. 자음·모음 분류는 조합 규칙 내부에서만 사용한다.
- 이 단계는 `100% 확정`으로 진행된다.
- 예: `ㄱ + ㅏ + ㅇ -> 자형: 강`

### 3.2. 자형의 역할
- 장비에 직접 장착 가능한 기초 아이템
- `결: 글자`, `결: 단어`, `결: 문장` 제작의 기본 재료
- 초반에는 낮은 비용으로 여러 조합을 실험하는 기반
- 일부 자형은 각인 전에도 빌드 방향을 잡는 데 활용 가능

### 3.3. 의미 각인
- 모든 자형이 곧바로 `결`이 되는 것은 아니다.
- 의미가 허용된 자형만 `결: 글자`로 각인할 수 있다.
- `결: 글자`부터는 `돌` 촉매와 골드 비용이 붙는다. 확률, `먹`, 희귀도는 상위 결부터 붙으며, 첫 수직 슬라이스의 제작은 실패하지 않는다.
- 즉, `자형`은 실험층이고 `결`은 완성층이다.

## 4. 결: 글자 각인

### 4.1. 정의
- `자형` 중 의미가 살아 있는 글자에 각인을 진행해 `결: 글자`를 만든다.

### 4.2. 역할
- `자형`보다 높은 수치와 고유 효과를 가진다.
- 단독 장착용 고급 아이템이 될 수 있다.
- 상위 `진언결`, `언령결` 제작의 재료가 된다.

### 4.3. 예시
- `자형: 강 + 각인 -> 결: 강`
- `자형: 불 + 각인 -> 결: 불`

## 5. 진언결 각인

### 5.1. 정의
- 여러 `자형` 또는 `결: 글자`를 모아 정해진 단어를 만들고, **돌: 새김** 계열 촉매를 사용해 패시브형 **진언결**로 각인한다.

### 5.2. 원칙
- 진언결은 자유 생성형이 아니라, 미리 정의된 단어만 결과물로 인정한다.
- 티어별 진언결 수량은 약 5개 내외로 제한한다.
- 진언결은 복잡한 룰 해석보다 `직관적인 전투 수치 옵션` 제공에 집중한다.
- 핵심 옵션 축은 `공격 속도`, `이동 속도`, `속성 공격력 % 증가`, `데미지 % 증가`, `치명타 확률`, `치명타 피해`, `언령 발동 확률`, `스턴 확률 증가`, `받는 스턴 시간 감소`, `받는 스턴 확률 감소`로 고정한다.
- 단, `언령 발동 확률`은 일반 옵션이 아니라 진언결에만 허용되는 특수 옵션 축으로 본다.
- `명중률`, `관통력`은 기본 옵션 축에서 제외한다.
- 회피 능력치(`회피 발동 확률`, `회피 시 피해 보정 확률`)는 전투 판정으로 존재하지만, 진언 옵션 축 편입 여부는 밸런스 단계에서 정한다.
- 역할은 `공격형`, `속도형`, `생존형`, `속성형`, `특수형`의 5축으로 고정한다.
- `공격형`은 `데미지/치명`, `속도형`은 `공속/이속`, `생존형`은 `받는 스턴 감소`, `속성형`은 `속성 공격력`, `특수형`은 `언령 발동 확률` 또는 `스턴 확률`을 담당한다.
- 치명타 설계는 `자형 = 낮은 입문 수치`, `진언결 = 높은 수치 또는 치명타 확률/피해 동시 제공` 원칙으로 구분한다.

### 5.3. 예시
- `자형: 태` + `자형: 양` + `돌: 새김` -> `결: 태양`
- `결: 강` + `결: 화` + `돌: 새김` -> `결: 강화`
- 위 `결: 강화` 조합은 런타임 데이터(`gyeol.json`)의 구성과 동일하게 유지한다.

## 6. 언령결 각인

### 6.1. 정의
- 여러 `자형` 또는 `결: 글자`를 모아 정해진 문장을 만들고, **돌: 말문** 계열 촉매를 사용해 확률 발동형 **언령결**로 각인한다.

### 6.2. 원칙
- 언령결은 정해진 문장만 결과물로 인정한다.
- `움결`, `무늬`는 초반 학습용 확장 티어로 각 속성 라인마다 `3개`씩 운영한다.
- `물결` 이후는 티어당 속성별 1개를 기본 원칙으로 한다.
- 상위 티어 언령결은 같은 속성의 하위 티어 언령결과 연계된다.
- 언령결은 무기 공격 적중 시 확률 발동하는 장착 효과다.
- 모든 언령결은 `단일 대상 1체`를 기준으로 설계한다.

### 6.3. 예시
- `자형: 어` + `자형: 둠` + `자형: 을` + `자형: 밝` ... + `돌: 말문` -> `결: 어둠을 밝히는 불꽃이여`

## 7. 보호/보정 재료

### 7.1. 먹 계열
- `먹: 지킴` = 실패 시 핵심 재료 보존
- `먹: 남김` = 실패 손실 완화
- `먹: 돋움` = 각인 성공률 소폭 증가

### 7.2. 적용 구간
- `씨앗 ~ 무늬`: 거의 사용하지 않음
- `물결 ~ 울림`: `먹: 남김` 중심
- `숨결 ~ 온결`: `먹: 지킴`, `먹: 남김`, `먹: 돋움`이 모두 중요

## 8. 천지인 각성
- 후반 `근원의 나라`에서 획득하는 `천지인`은 새 언령결을 만드는 재료가 아니다.
- 대신 이미 보유한 낮은 티어 언령결을 강화하는 각성 재료다.
- 강화 시 성능과 연출이 상승하며, 특정 언령결의 발동 확률을 직접 높일 수 있다.
- 단, 천지인 강화를 포함한 최종 발동 확률은 `20%`를 넘지 못한다.
