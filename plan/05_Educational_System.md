# [기획서] 05. 교육용 한글 학습 시스템 (Educational System)

## 1. 학습 목표 및 타겟
- **타겟:** 
  - 한글 조합의 재미를 자연스럽게 익히고 싶은 대중형 액션 RPG 유저
  - 미래 아포칼립스 판타지 안에서 문자 규칙을 배우고 싶은 입문자
- **학습 목표:** 
  - 자음과 모음의 조합 원리(모아쓰기) 직관적 이해
  - 글자와 속성, 단어와 효과의 연결 학습

---

## 2. 단계별 학습 커리큘럼 (Dungeon Progression)
던전의 난이도가 올라갈수록 한글 조합의 복잡도도 함께 상승합니다.

| 던전 단계 | 학습 주제 | 조합 난이도 | 예시 단어 |
| :--- | :--- | :--- | :--- |
| **Stage 1** | 기본 자모음 | 초성 + 중성 (CV) | 가, 나, 다, 라 |
| **Stage 2** | 받침의 이해 | 초성 + 중성 + 종성 (CVC) | 강, 산, 불, 물 |
| **Stage 3** | 복합 모음/자음 | ㄲ, ㄸ, ㅐ, ㅘ 등 포함 | 해, 꽃, 땅, 과일 |
| **Stage 4** | 다음절 단어 | 2글자 이상의 진언결 | 학교, 사과, 친구 |

---

## 3. 오디오 피드백 방향
사용자가 조합과 전투를 반복하면서도 피로하지 않도록, 차갑고 선명한 미래 판타지 전자음 계열의 사운드를 지향합니다.

### 3.1. 보이스 피드백 (Voice Guide)
- **가이드 정령:** 맑지만 가볍지 않은 톤으로 발음과 의미를 안내합니다.
- **파편 획득 시:** 짧고 또렷하게 자모를 읽어주며 조합의 감각을 살립니다.
- **결 완성 시:** 완성된 단어나 문장을 힘 있게 읽어주며 결의 의미를 강조합니다.
- **대기 상태:** 과도하게 말을 걸기보다 짧은 힌트만 제공합니다.

### 3.2. 효과음 설계
| 액션 | 사운드 특징 (Description) | 예시 의성어 |
| :--- | :--- | :--- |
| **파편 획득** | 얇은 금속성과 잔광이 남는 짧은 수집음 | *팅, 챙* |
| **글자 조합 중** | 에너지 조각이 맞물리는 기계적 공명음 | *칙, 탁* |
| **글자 완성 (Glyph)** | 빛이 응축되는 짧은 결속음 | *츠응, 팟* |
| **진언결 각인/발동** | 결이 새겨질 때 울리는 짧은 파동음 | *웅, 챠악* |
| **조합 실패** | 결이 흩어지는 낮은 잡음과 잔향 | *즈읍, 탁* |

### 3.3. 배경 음악 (BGM)
- **로비/거점:** 잔향이 긴 신스 패드와 맑은 멜로디가 섞인 고요한 미래 판타지 음악
- **던전 전투:** 리듬감 있는 전자 타악과 긴장감 있는 스트링/패드가 섞인 전투 음악

---

## 4. 시각적 연출과 연동 (Visual & Audio Sync)
- **폰트 연출:** 글자가 완성될 때 글자 주변에 짧고 단단한 공명 애니메이션과 결 파편 잔광이 튑니다.
- **색상 테마:** 자음과 모음은 시각적으로 구분하되, 파스텔 톤보다 선명한 속성광과 먹빛 대비를 우선합니다.

---

## 5. 아트 스타일 조정 (Visual Tone)
- **방향:** `엘리멘탈 사가`에 가까운 미래 아포칼립스 판타지
  - 무너진 문명, 공허한 하늘, 차가운 빛, 결의 에너지
  - 과도한 피와 훼손을 배제한 비고어 전투 연출
  - 캐릭터는 속성 실루엣과 갑주 오라가 분명한 형태로 표현
