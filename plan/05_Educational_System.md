# [기획서] 05. 교육용 한글 학습 시스템 (Educational System)

## 1. 학습 목표 및 타겟
- **타겟:** 
  - 한글을 처음 접하는 외국인 입문자 (K-Pop/K-Drama 팬 등)
  - 글자를 익히기 시작하는 국내외 어린이 (5~9세)
- **학습 목표:** 
  - 자음과 모음의 조합 원리(모아쓰기) 직관적 이해.
  - 기초 어휘(명사, 동사)의 시각적/청각적 매칭 학습.

---

## 2. 단계별 학습 커리큘럼 (Dungeon Progression)
던전의 난이도가 올라갈수록 한글 조합의 복잡도도 함께 상승합니다.

| 던전 단계 | 학습 주제 | 조합 난이도 | 예시 단어 |
| :--- | :--- | :--- | :--- |
| **Stage 1** | 기본 자모음 | 초성 + 중성 (CV) | 가, 나, 다, 라 |
| **Stage 2** | 받침의 이해 | 초성 + 중성 + 종성 (CVC) | 강, 산, 불, 물 |
| **Stage 3** | 복합 모음/자음 | ㄲ, ㄸ, ㅐ, ㅘ 등 포함 | 해, 꽃, 땅, 과일 |
| **Stage 4** | 다음절 단어 | 2글자 이상의 룬워드 | 학교, 사과, 친구 |

---

## 3. 귀엽고 친근한 오디오 피드백 (Cute Audio Design)
사용자가 학습 과정에서 스트레스를 받지 않고 즐거움을 느낄 수 있도록 '버블팝(Bubble Pop)' 스타일의 사운드를 지향합니다.

### 3.1. 보이스 피드백 (Voice Guide)
- **한글 요정 (The Hangeul Sprite):** 5~7세 아이나 맑은 톤의 여성 성우 목소리로 발음을 안내합니다.
- **파편 획득 시:** "ㄱ(기역)!", "ㅏ(아)!" 하며 짧고 경쾌하게 외칩니다.
- **단어 완성 시:** "와! '사과'가 완성되었어!" 하며 칭찬하는 톤으로 전체 단어를 읽어줍니다.
- **대기 상태:** 오랫동안 조작이 없으면 "어떤 글자를 만들어볼까?" 하며 귀엽게 말을 겁니다.

### 3.2. 효과음 설계 (Cute SFX)
| 액션 | 사운드 특징 (Description) | 예시 의성어 |
| :--- | :--- | :--- |
| **파편 획득** | 비눗방울이 터지는 듯한 가볍고 맑은 소리 | *톡!, 퐁!* |
| **글자 조합 중** | 나무 블록이 서로 부딪히는 따뜻한 소리 | *탁, 또각* |
| **글자 완성 (Glyph)** | 작은 별이 반짝이는 듯한 금속성 챠임벨 소리 | *티링~, 뾰로롱* |
| **룬워드 발동** | 짧고 경쾌한 팡파르 (부담스럽지 않은 볼륨) | *따따따~!, 쨔잔!* |
| **조합 실패** | 스프링이 튀는 듯한 익살스러운 소리 (불쾌감 방지) | *보잉~, 휘이익* |

### 3.3. 배경 음악 (BGM)
- **로비/마을:** 실로폰이나 피치카토(현을 튕기는 주법) 위주의 평화롭고 아기자기한 음악.
- **던전 전투:** 리듬감은 있지만 너무 긴박하지 않은, '장난감 병정의 행진' 같은 느낌의 곡.

---

## 4. 시각적 연출과 연동 (Visual & Audio Sync)
- **폰트 연출:** 글자가 완성될 때 글자 주변에 '말랑말랑한' 애니메이션(Bounce 효과)과 함께 음표 파티클이 튑니다.
- **색상 테마:** 자음은 파란색 계열, 모음은 빨간색 계열의 파스텔 톤을 사용하여 시각적으로도 구분하기 쉽게 구성합니다.

---

## 5. 아트 스타일 조정 (Visual Tone)
- **기존:** 어둡고 기괴한 디아블로풍 던전.
- **변경:** **'네온 판타지(Neon Fantasy)'** 또는 **'마법 도서관(Magic Library)'** 스타일.
  - 가시성이 높은 밝은 톤의 3D 그래픽.
  - 몬스터는 '먹물 괴물'이나 '낙서 생물'처럼 귀엽고 개성 있는 디자인으로 변경하여 폭력성 완화.
