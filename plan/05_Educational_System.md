# [기획서] 05. 한글 조합 학습 UX (Hangul Learning UX)

## 1. 방향
이 문서는 별도 교육용 모드가 아니라, 액션 수집 RPG 안에서 한글 조합 규칙을 자연스럽게 익히게 만드는 UX 원칙을 정의한다.

- 1차 타깃은 한글 조합의 재미를 자연스럽게 익히고 싶은 대중형 액션 RPG 유저다.
- 게임의 핵심은 학습 앱이 아니라 `자모 파편 -> 자형 -> 결 -> 진언결/언령결` 성장 루프다.
- 학습 요소는 튜토리얼, 제작 UI, 피드백, 보상 흐름 안에 녹인다.
- 화면 안에서 긴 설명문을 반복 노출하지 않는다.
- 한글 규칙을 모르는 유저도 조합 결과와 전투 효과를 통해 규칙을 추론할 수 있어야 한다.

## 2. 학습 목표
- 자음과 모음의 조합 원리, 즉 모아쓰기 구조를 직관적으로 이해한다.
- 초성, 중성, 종성이 전투 옵션과 어떻게 연결되는지 이해한다.
- `자형`은 100% 확정 조합이고, `결`은 의미 각인을 거친 완성층이라는 차이를 이해한다.
- 단어형 진언결과 문장형 언령결이 단순 수집물이 아니라 빌드 목표라는 점을 이해한다.

## 3. 단계별 학습 흐름

| 단계 | 학습 주제 | 조합 난이도 | 예시 결과 | 게임 내 사용처 |
| :--- | :--- | :--- | :--- | :--- |
| Stage 1 | 기본 자모 | 초성 + 중성 | `가`, `나`, `다`, `라` | 자모 파편 습득과 첫 자형 조합 |
| Stage 2 | 받침 구조 | 초성 + 중성 + 종성 | `강`, `산`, `불`, `물` | 초반 자형 장착과 결: 글자 각인 |
| Stage 3 | 복합 자모 | 쌍자음, 복합 모음 포함 | `빛`, `꽃`, `땅`, `과` | 중급 자형과 속성 라인 분화 |
| Stage 4 | 단어 조합 | 2글자 이상 | `강화`, `철벽`, `태양` | 진언결 제작 |
| Stage 5 | 문장 조합 | 여러 자형/결 조합 | `앞을 밝혀라` | 언령결 제작과 발동 체험 |

- `아르카디아 수직 슬라이스`에서는 Stage 1~2와 Stage 5의 체험형 언령결 2개만 우선 검증한다.
- Stage 3~4는 데이터와 UI 구조만 열어두고, 실제 콘텐츠는 후속 확장으로 늘린다.

## 4. 튜토리얼 UX 원칙
- 첫 조합은 실패 없이 진행한다.
- `자형` 제작은 항상 100% 확정임을 명확히 보여준다.
- `결: 글자`부터 확률, `돌`, `먹`이 붙는다는 차이를 제작 UI에서 분리해 보여준다.
- 첫 언령결은 스토리 보상으로 지급해 발동 감각을 먼저 체험시킨다.
- 이후 제작형 언령결을 열어 목표 파밍으로 연결한다.
- 설명은 `나랏`의 짧은 대사, 제작 UI의 요구 재료, 결과 미리보기로 나눠 제공한다.

## 5. UI 피드백 원칙

### 5.1. 조합 화면
- 자모 파편은 슬롯형 인벤토리가 아니라 수량형 재화로 표시한다.
- 선택한 자모가 어떤 글자로 조합되는지 즉시 미리보기로 보여준다.
- 유효한 조합이면 `자형` 결과를 밝게 표시한다.
- 아직 의미 각인이 불가능한 자형은 `각인 가능` 상태와 구분한다.

### 5.2. 각인 화면
- `자형 -> 결: 글자`와 `결/자형 -> 진언결/언령결`을 같은 화면에 섞지 않는다.
- `돌: 새김`, `돌: 말문`, `돌: 깃듦`의 사용처를 명확히 구분한다.
- `먹: 지킴`, `먹: 남김`, `먹: 돋움`은 실패 리스크 설명과 함께 표시한다.
- 성공률은 숫자로 표시하되, 과도한 공포감을 주는 연출은 피한다.

### 5.3. 전투 피드백
- 언령결 발동은 기본 타격 뒤에 붙는 보조 폭발감으로 보여준다.
- 일반 피해, 치명타, 언령 피해 숫자는 색상과 크기로 구분한다.
- 언령결은 단일 대상 1체만 공격하므로, 연출이 넓어도 실제 판정 대상은 명확히 보여야 한다.

## 6. 오디오 피드백

| 액션 | 사운드 방향 | 예시 의성어 |
| :--- | :--- | :--- |
| 파편 획득 | 얇은 금속성과 잔광이 남는 짧은 수집음 | `팅`, `챙` |
| 자모 선택 | 에너지 조각이 맞물리는 기계적 공명음 | `칙`, `탁` |
| 자형 완성 | 빛이 응축되는 짧은 결속음 | `츠응`, `팟` |
| 결 각인 성공 | 결이 새겨질 때 울리는 짧은 파동음 | `웅`, `챠악` |
| 각인 실패 | 결이 흩어지는 낮은 잡음과 잔향 | `즈읍`, `탁` |
| 언령결 발동 | 속성별 타격감이 있는 짧은 폭발음 | `화륵`, `쾅`, `파직` |

## 7. 보이스와 텍스트 톤
- 보이스는 학습 설명보다 세계관 가이드와 짧은 반응에 집중한다.
- `나랏`은 자모/자형/결의 관계를 짧은 문장으로 설명한다.
- UI 문구는 초등 학습 교재처럼 쓰지 않고, 게임 내 제작/각인 용어를 일관되게 사용한다.
- 예: `자모 파편을 조합해 자형을 만들 수 있습니다. 자형 조합은 100% 성공합니다.`
- 예: `의미가 허용된 자형에는 결 각인을 진행할 수 있습니다.`
- 예: `정해진 문장을 완성하면 언령결을 각인할 수 있습니다.`

## 8. 배경 음악
- **거점:** 잔향이 긴 신스 패드와 맑은 멜로디가 섞인 고요한 미래 판타지 음악
- **필드:** 낮은 드론과 반복 리듬으로 황폐한 세계의 긴장감을 유지
- **던전 전투:** 전자 타악과 긴장감 있는 스트링/패드를 섞어 수동 공략감을 강화
- **보스전:** 속성 언령 발동과 약점 노출이 읽히도록 타격음과 주요 효과음을 우선한다

## 9. 시각적 연출과 연동
- 글자가 완성될 때 주변에 짧고 단단한 공명 애니메이션과 결 파편 잔광이 튄다.
- 자음과 모음은 시각적으로 구분하되, 파스텔 톤보다 선명한 속성광과 먹빛 대비를 우선한다.
- 배경은 어둡고 황폐하지만, 조합 결과와 속성 색은 항상 선명하게 읽혀야 한다.
- 학습 안내 UI도 게임의 미래 아포칼립스 판타지 톤을 유지한다.

## 10. 첫 수직 슬라이스 적용 범위
- `자모 파편` 습득
- `자형: 화`, `자형: 강` 수준의 기본 조합
- `결: 화` 또는 동급 `결: 글자` 1회 각인
- 진언결 `2~3개`의 장착과 효과 확인
- 언령결 `결: 앞을 밝혀라`, `결: 불길아 번져라`의 발동 체험
- `나랏`을 통한 짧은 가이드 문구
- 제작 UI의 결과 미리보기와 재료 요구량 표시

## 11. 명시적으로 하지 않는 것
- 별도 학습 모드
- 문제풀이형 한글 퀴즈
- 어린이용 교재식 설명문
- 장시간 튜토리얼 대화
- 전투와 분리된 교육 미니게임
