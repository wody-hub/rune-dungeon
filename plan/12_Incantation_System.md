# [기획서] 12. 언령결 시스템 (Incantation System)

## 1. 개요
- 언령결은 문장형 발동 결이다.
- `자형` 또는 `결: 글자`를 모아 정해진 문장을 완성하고, `돌: 말문`을 사용해 각인해야 한다.
- 언령결은 단순 문장 수집이 아니라, 티어와 속성별로 기획된 발동 효과 테이블이다.
- 언령결의 역할은 복잡한 계산보다 `확률 발동되는 속성 데미지와 화려한 연출`에 있다.

## 2. 핵심 원칙
- `씨앗` 티어 언령결은 미도입을 유지한다.
- 레벨 정책은 `씨앗 Lv 1~9`, `움결 Lv 10~39`, `무늬 Lv 40~69`, `물결 Lv 70~99`, `울림 Lv 100~129`, `숨결 Lv 130~159`, `빛살 Lv 160~189`, `여울 Lv 190~199`, `온결 Lv 200`으로 고정한다.
- 후반 티어는 속성별 1개를 기본 원칙으로 한다.
- 초반 제작 학습 구간인 `움결`, `무늬`는 각 속성 라인마다 언령결 `3개`씩을 운영한다.
- `움결` 티어는 각 속성의 언령결 3개 중 2개는 스토리 던전에서 확정 지급하고, 나머지 1개는 제작으로 획득하게 한다.
- `무늬` 티어는 각 속성의 언령결 3개 중 1개는 스토리 던전에서 확정 지급하고, 나머지 2개는 제작으로 획득하게 한다.
- 상위 티어 언령결은 같은 속성의 하위 티어 언령결과 연계된다.
- 하위 언령결은 후반 `천지인` 각성으로 다시 강화할 수 있다.
- 빌드의 깊이와 계산은 `진언결`이 담당하고, 언령결은 그 결과를 화면에 강하게 드러내는 `확률 발동 축`으로 둔다.
- 언령결은 광역 섬멸기가 아니라 `단일 대상 1:1 전투용 확률 발동 효과`를 원칙으로 한다.
- 언령결은 플레이어 입력으로 직접 사용하는 구조를 사용하지 않는다.
- 기본 공격 또는 특정 무기 행동이 적중할 때 발동 판정을 수행한다.
- `언령 발동 확률`은 진언결 중심으로만 제한적으로 허용되는 특수 옵션이다.

## 3. 생성 규칙

### 3.1. 문장 일치 규칙
- 언령결은 정해진 문장을 정확히 완성해야 한다.
- 단어가 아닌 문장만 언령결로 인정된다.

### 3.2. 각인 규칙
- `자형` 또는 `결: 글자` 배열 완료
- `돌: 말문` 소모
- 필요 시 `돌: 깃듦` 추가
- 선택적으로 `먹: 지킴`, `먹: 남김`, `먹: 돋움` 사용
- 성공 시 언령결 완성

### 3.3. 제작 흐름
- `음 -> 자형 합성`은 `100% 확정`이다.
- 언령결은 그 위에서 `자형`에 의미를 연결하는 상위 각인 콘텐츠다.
- 낮은 티어는 `자형`만으로도 진입 가능하지만, 상위 티어는 `결: 글자`와 상위 `돌`의 중요도가 커진다.
- 첫 언령결만큼은 스토리 던전 확정 지급으로 체험시키고, 이후부터 제작 목표를 열어준다.

### 3.4. 초기 해금 구조
- `씨앗`: 미도입
- `움결`: 각 속성별 3개 기획
- `움결`: 각 속성별 스토리 진행 중 2개 확정 지급, 1개 제작 획득
- `무늬`: 각 속성별 3개 기획
- `무늬`: 각 속성별 스토리 진행 중 1개 확정 지급, 2개 제작 획득
- `물결` 이후: 티어당 속성별 1개를 기본 구조로 전환한다.

## 4. 장착 구조
- 언령결은 무기 전용 슬롯에 장착한다.
- 무기에는 일반 진언 슬롯과 분리된 언령 슬롯이 존재한다.
- 언령결은 퀵슬롯 사용형이 아니라, 장착 시 전투 중 자동 판정을 통해 발동한다.

## 5. 사용 구조
- 낮은 티어 언령결은 상대적으로 발동 기회가 많고 즉응성이 좋다.
- 높은 티어 언령결은 발동 확률이 낮거나 조건이 더 엄격하지만, 한 번 터질 때 결정력이 높다.
- 언령결 자체는 기본적으로 `속성 데미지`만 가진다.
- 상태 이상, 보호, 관통, 약화 같은 세부 전투 계산은 언령결 고유 효과가 아니라 `진언결 세팅`에 의해 변형된다.
- 즉, 같은 화염 언령결이라도 실제 위력과 부가 계산은 플레이어의 진언 구축에 따라 달라진다.
- 모든 언령결은 기본적으로 `주 대상 1체`를 공격한다.
- 주변 적에게 연쇄되거나 폭발 반경으로 확산되는 광역형 설계는 초중후반 전체에서 채택하지 않는다.
- 강한 언령결일수록 발동 확률 또는 발동 조건이 무거워지는 대신, `한 대상 집중 화력`이 강화되는 방향으로 설계한다.
- 언령결은 별도 사용 버튼보다 `기본 공격 적중 -> 발동 판정 -> 발동 연출` 흐름으로 읽히게 한다.
- 같은 화염 언령결이라도 `대검계열`, `활계열`, `지팡이계열`은 기본 공격 동작 위에 다른 발동 연출을 얹을 수 있다.

## 5.1. 발동 규칙
- 언령결은 기본적으로 무기 공격 적중 시 확률 판정을 수행한다.
- 언령결은 별도의 내부 쿨다운 없이, 타격마다 독립적인 확률 판정을 수행한다.
- 같은 1회의 타격에서 여러 언령결이 동시에 발동할 수 있다.
- 동시에 발동에 성공한 언령결은 모두 개별 피해를 적용한다.
- 발동 연출 역시 억제 없이 함께 중첩 출력하며, 언령결의 확률형 폭발감을 전투 정체성으로 삼는다.
- 단, 모든 언령결은 끝까지 `단일 대상 1체`만 공격한다.
- 언령결의 체감 성능은 `기본 발동 확률`, `추가 언령 발동 확률`, `적중 빈도`, `무기군 공격 속도`의 조합으로 결정된다.
- 언령결 밸런싱의 기준은 개별 언령 1개의 기대값보다 `초당 총 발동 기대값`에 둔다.
- 발동 확률은 밸런스 붕괴를 막기 위해 상한선을 두며, 최종 상한은 `20%`로 고정한다.
- 진언결이 제공하는 `언령 발동 확률` 옵션은 개별 옵션당 `1~2%` 수준의 낮은 수치만 허용한다.
- 초기 `4티어(움결, 무늬, 물결, 울림)` 언령결의 기본 발동률은 `3%` 고정으로 시작한다.
- 이후 고위 티어 언령결의 기본 발동률은 `1%`를 기본값으로 사용한다.
- 상위 티어 언령결은 단순 발동률 상승보다 `발동 시 위력`, `속성 정체성`, `특수 연출`로 차별화한다.
- 공속이 빠른 무기군은 더 많은 발동 기회를 갖고, 느린 무기군은 기본 옵션이나 빌드 보정으로 발동 확률을 더 높게 가져가는 방향을 허용한다.

## 5.2. 보스 기믹 연동 원칙
- 보스 약점 파훼를 언령결의 랜덤 발동에만 전적으로 의존시키지 않는다.
- 먼저 `올바른 속성/세팅 장착`, `근접 적중`, `약점 노출` 같은 확정 조건으로 파훼 창을 연다.
- 약점 노출 상태에서는 필요한 속성 언령이 확정 발동하거나, 발동 판정이 사실상 보장되는 예외 규칙을 둘 수 있다.
- 이후 일반 상태의 언령 발동은 추가 보상, 그로기 심화, 딜 증폭 역할을 맡는다.
- 이 원칙으로 인해 플레이어는 RNG만 기다리는 것이 아니라, 세팅과 타이밍으로 패턴을 통제할 수 있어야 한다.

## 6. 속성 구조
- 기본 속성은 불, 물, 땅, 바람, 빛, 어둠
- `움결`, `무늬`는 초반 학습용 확장 티어로서 각 속성 라인마다 3개씩 기획한다.
- `물결` 이후 각 티어마다 속성별 1개를 기본으로 설계한다.
- 속성별 계보를 따라 언령결이 강화되는 구조

## 6.1. 초기 티어 공급 정책
- `움결`은 각 속성 라인마다 `스토리 2개 + 제작 1개` 구조로, 언령 사용 경험과 첫 제작 경험을 동시에 연다.
- `무늬`는 각 속성 라인마다 `스토리 1개 + 제작 2개` 구조로, 스토리 의존도를 낮추고 제작 비중을 높인다.
- 초반 스토리 지급 언령결은 범용성과 가독성이 높은 효과를 우선 배치한다.
- 초반 제작 언령결은 유저가 자형 조합, `돌: 말문`, 실패 보정 재료 사용을 실제로 익히게 만드는 학습 목표를 맡는다.
- 제작 전용 언령결은 각 속성 보스의 `음`/촉매 파밍과 직접 연결한다.

## 6.2. 속성별 초기 운영 원칙
- `움결`, `무늬`에서도 기본 6속성을 모두 운영한다.
- 각 속성의 차이는 기본적으로 `속성 종류`, `발동 감각`, `타격 연출`, `사거리`, `적중 체감`에 둔다.
- 초기 스토리 지급은 각 속성 라인에서 사용감과 화면 연출이 잘 보이는 2개를 우선 배치하고, 제작 1개는 같은 속성 안의 다른 타격 감각을 보여주는 형태로 둔다.

## 6.3. 지급 순서와 보스 연결
- 각 속성 라인의 첫 `움결` 언령은 속성 소개용 스토리 보상으로 지급한다.
- 두 번째 `움결` 언령은 같은 속성의 다른 사거리/타격 감각을 보여주는 중반 스토리 보상으로 지급한다.
- 세 번째 `움결` 언령은 해당 속성 보스 파밍을 통해 제작하도록 유도한다.
- `무늬` 티어는 진입 직후 대표 1개를 스토리로 지급하고, 나머지 2개는 속성 메인 보스를 중심으로 제작 해금한다.
- 예시 연결:
  - 불: `몽당연필 기사단장` -> `여명 집행관`
  - 물: `서릿발 서고 수호자`
  - 땅: `붕괴한 성벽 거신`
  - 바람: `유리폭풍 추적자`
  - 빛: `여명 집행관`
  - 어둠: `망각의 잉크 드래곤` -> `침묵의 심연 군주`
- 제작 언령결의 완성 시점은 티어 레벨 구간에 묶지 않는다. 각 속성의 제작 언령결은 해당 속성 보스를 처음 만나는 지역에서 열리며, 대표 보스가 중후반 지역에 있는 속성(물, 바람, 빛)은 `움결` 제작 완성이 늦어지는 것을 의도된 설계로 둔다.
- 따라서 스토리 지급 2개만으로 해당 티어 구간의 전투가 성립해야 하며, 늦게 완성한 하위 언령결은 후반 `천지인` 각성으로 가치가 보존된다.

## 7. 후반 각성
- `근원의 나라`에서 획득하는 `천지인` 재료는 낮은 티어 언령결을 강화한다.
- 강화 시 성능 상승과 이펙트 변화가 발생한다.
- `천지인`은 일반 진언 옵션과 별개로, 특정 언령결 자체의 발동 확률을 직접 강화할 수 있다.
- 이 강화는 모든 언령에 공용으로 적용되는 것이 아니라, 강화 대상이 된 개별 언령결에 귀속된다.
- 단, `천지인`을 포함한 모든 보정을 합쳐도 최종 발동 확률은 `20%`를 넘지 못한다.

## 8. 연출 방향
- 강한 언령결은 흑백 대비, 네온 광채, 결 파동, 글자 발광을 적극 사용한다.
- 낮은 티어는 직관성과 가독성, 높은 티어는 압도적인 존재감을 목표로 한다.
- 단, 화면을 덮는 광역 장판이나 대량 타격 연출은 지양하고, `한 대상을 꿰뚫는 집중 타격감`을 우선한다.
