# [기획서] 13. 상세 전투 AI 및 몬스터 도감 (Monster & AI Design)

## 1. 몬스터 디자인 컨셉 (Concept Art)
미래 아포칼립스 판타지 세계에서 결의 에너지를 뒤틀리게 흡수한 **침식체**, **기계 잔해 생명체**, **먹빛 괴수**를 주요 적으로 설정합니다. 타격 시 피 대신 결 파편, 먹빛 잔광, 에너지 균열이 흩어지는 식으로 연출합니다.

첫 수직 슬라이스에서는 `아르카디아`만 `공유 마을 허브`이며, `음` 파밍을 포함한 모든 게임플레이 구역은 `포털`로 연결되는 최대 4인 `협동 인스턴스`다.

## 2. 몬스터 등급 및 기본 AI 패턴
몬스터는 등급에 따라 행동 패턴의 복잡도가 달라집니다.

| 등급 | 행동 패턴 (AI Pattern) | 특징 및 피드백 |
| :--- | :--- | :--- |
| **일반 (Normal)** | 단순 추적(Chase) 및 근접 공격 | 공격 모션이 느리고 직관적. 플레이어가 `1:1 타깃 처리` 감각을 익히는 입문 상대 역할. |
| **정예 (Elite)** | 위치 이탈, 원거리 사격, 버프 부여 | 플레이어의 공격 템포를 흔들고, 언령 발동 기대 타이밍을 꼬이게 만들며, 체력이 낮아지면 뒤로 도망침. |
| **보스 (Boss)** | 페이즈 전환, 집중 압박 패턴, 특정 '글자' 약점 노출 | 공격 전 명확한 예고 동작으로 위험을 읽히고, 특정 진언결/언령결에 추가 반응을 보일 수 있음. |

## 3. 구역별 몬스터 도감 (Bestiary by Region)

도감은 `plan/14`의 구역 구조(`아르카디아`의 새벽 들판·흑심 채굴장, `드라실`의 먹빛 서고 등)를 기준으로 배치한다. 과거의 단일 던전 층 구조(`1층`, `2층`)는 사용하지 않는다.

### 3.0. MVP 일반 몬스터 수치 기준
첫 수직 슬라이스에서 검증할 일반 몬스터는 `먹물 슬라임` 1체를 기준으로 설계한다.

| 항목 | 값 | 메모 |
| :--- | :--- | :--- |
| 기준 몬스터 | `먹물 슬라임` | 첫 MVP 상대 |
| 체력 | `140` | 기본 치명타와 언령까지 감안한 초반 입문 상대 |
| 이동 속도 | `42px/초` | 플레이어보다 느리게 추적 |
| 감지 거리 | `180px` | 지나치게 멀리서 반응하지 않음 |
| 근접 사거리 | `28px` | 플레이어에게 바짝 붙어야 공격 가능 |
| 공격 모션 길이 | `1.4초` | 플레이어 대검보다 조금 더 느리다 |
| 공격 발생 시점 | `420ms` | 예고를 읽고 피하거나 먼저 때릴 수 있어야 한다 |
| 기본 피해 | `18` | 초반 3~4대는 버틸 수 있는 수준 |
| 피격 경직 | `260ms` | 대검 `220ms`보다 약간 길게 두어 초반 손맛 강화 |
| 경직 저항 | `0%` | 입문 몬스터는 저항 없음 |
| 처치 보상 | `음 1~2개`, `소량 골드` | 루프 검증용 최소 보상 |

- 초반 일반 몬스터는 `1:1 압박과 패턴 피하기 학습`을 우선한다.
- 언령 발동이 없어도 처치 가능해야 하고, 발동이 터지면 분명히 전투 시간이 짧아져야 한다.
- 활은 공속 체감, 지팡이는 발동 체감, 대검은 버티기와 한 방 감각을 이 몬스터로 먼저 검증한다.
- 방어 공식상 피해는 항상 최소 `1`이 보장되므로, 초반 몬스터도 완전히 무효화되지는 않는다.
- MVP 기준 플레이어 기본 방어력 `12`에 이 몬스터 기본 피해 `18`를 적용하면, 일반 피격은 약 `16` 수준으로 들어오고 대검은 추가 방어 보상으로 더 낮아진다.
- MVP 대검의 `24~32`는 무기 공격력 굴림과 STR 보너스를 더한 피해 계수 적용 전 범위이며, 비치명타 방어력 계산 전 범위는 `34.8~46.4`다. 기본 치명타를 반영한 평균 기대 피해 `41.615`를 먹물 슬라임의 방어력 `0`에 적용하면 최종 피해 기대 기준은 약 `41`이다. 현재 체력 `140`은 첫 서버 전투 테스트에서 관측한 처치 시간으로 재조정하기 전까지 유지하며, 고정 타수로 확정하지 않는다.

### 3.1. 아르카디아: 새벽 들판 (Dawn Field)
초보자 구간으로, 몬스터의 이동 속도가 느리고 공격력이 낮습니다. 드랍: 기본 `음`.

- **먹물 슬라임 (Ink Slime):** 
  - **특징:** 바닥을 기어 다니는 검은 유체형 침식체. 타격 시 먹빛 파편이 흩어진다.
  - **AI:** 플레이어를 발견하면 천천히 다가와 몸통 박치기.
  - **MVP 수치:** 체력 `140`, 이동 속도 `42px/초`, 근접 사거리 `28px`, 공격 모션 `1.4초`, 공격 발생 시점 `420ms`, 기본 피해 `18`
- **낙서 박쥐 (Scribble Bat):** 
  - **특징:** 결 문자가 뒤틀려 생긴 박쥐형 괴체. 공중에 떠 있어 타격감이 독특함.
  - **AI:** 플레이어 주변을 빙빙 돌다가 일직선으로 돌진.

### 3.2. 아르카디아: 흑심 채굴장 (Blackheart Mine)
첫 던전 구간. 상태 이상(CC)을 유발하는 정예 몬스터가 처음 등장합니다. 드랍: 기본 `음`, 각인용 `돌: 새김`.

### 3.2.0. MVP 정예 몬스터 수치 기준
첫 정예 몬스터 검증은 `오타 요정` 1체를 기준으로 설계한다.

| 항목 | 값 | 메모 |
| :--- | :--- | :--- |
| 기준 몬스터 | `오타 요정` | 첫 정예 상대 |
| 체력 | `320` | 치명타와 언령 발동을 감안한 첫 정예 체감용 |
| 이동 속도 | `68px/초` | 플레이어 위치를 더 적극적으로 흔든다 |
| 감지 거리 | `240px` | 일반 몬스터보다 넓게 반응 |
| 원거리 사거리 | `220px` | 지팡이보다 길고 활보다는 짧은 압박 거리 |
| 공격 모션 길이 | `1.05초` | 일반보다 빠르고 읽을 수는 있어야 한다 |
| 공격 발생 시점 | `260ms` | 빠른 예고 후 발사 |
| 기본 피해 | `28` | 일반보다 위협적이지만 즉사급은 아님 |
| 피격 경직 | `140ms` | 일반 몬스터보다 짧아 연속 압박 허용 |
| 경직 저항 | `20%` | 무한 경직 방지 |
| 특수 패턴 | `혼란 2초` | 이동 방향 반전 |
| 처치 보상 | `음 2~4개`, `소량 골드`, `하위 촉매 낮은 확률` | 정예 보상 체감 |

- 정예는 일반 몬스터보다 `체력`, `압박 속도`, `경직 저항`이 높아야 한다.
- 플레이어는 대검의 버티기, 활의 공속, 지팡이의 높은 발동 확률 차이를 이 몬스터에서 더 분명히 체감해야 한다.
- MVP 기준 플레이어 기본 방어력 `12`에 이 몬스터 기본 피해 `28`를 적용하면 일반 피격은 약 `25` 수준이며, 대검은 추가 방어 보상으로 약 `23` 수준까지 낮아진다.
- MVP 대검의 `24~32`는 피해 계수 적용 전 범위이고, `34.8~46.4`는 비치명타 방어력 계산 전 범위다. 기본 치명타를 반영한 평균 기대 피해 `41.615`를 오타 요정의 방어력 `10`에 적용하면 최종 피해 기대값은 `37.832`다. 현재 체력 `320`은 첫 서버 전투 테스트에서 관측한 처치 시간으로 재조정하기 전까지 유지하며, 고정 타수로 확정하지 않는다.

- **지우개 골렘 (Eraser Golem):** 
  - **특징:** 문자 구조를 마모시키는 거대한 잔해형 골렘. 방어력이 매우 높음.
  - **AI:** 플레이어가 남긴 강화 흔적이나 보조 오브젝트를 짓밟아 무효화함.
- **오타 요정 (Typo Sprite):** 
  - **특징:** 깨진 결이 모여 생긴 불안정한 소형 정령.
  - **AI:** 멀리서 '잘못된 글자' 형태의 발사체를 던지며, 맞으면 2초간 이동 방향이 반대가 되는 혼란 부여.
  - **MVP 수치:** 체력 `320`, 이동 속도 `68px/초`, 원거리 사거리 `220px`, 공격 모션 `1.05초`, 공격 발생 시점 `260ms`, 기본 피해 `28`, 피격 경직 `140ms`

## 4. 보스 몬스터 상세 기획 (Boss Encounters)
보스전은 단순한 딜찍누가 아니라, **언령결과 속성 대응을 활용한 기믹 파훼**가 핵심입니다.

### 전투 설계 원칙
- 플레이어 전투는 기본적으로 `한 번에 적 1체를 상대하는 구조`를 기준으로 설계한다.
- 광역 공격이나 다수 적 동시 삭제 쾌감보다는, 타깃 선정과 패턴 대응의 긴장감을 우선한다.
- 몬스터 수를 늘려 난이도를 올리기보다, 개별 적의 위치와 공격 타이밍으로 압박을 만든다.

### 보스 파밍 원칙
- 각 보스는 `메인 속성 1개`와 `보조 속성 1~2개`를 가진다.
- 플레이어는 원하는 속성 빌드에 따라 돌아야 할 보스를 명확히 선택할 수 있어야 한다.
- 모든 속성 보스는 자기 속성 언령결 제작에 필요한 `돌: 말문`을 저확률 직드랍과 `돌: 말문 조각` 누적 보장으로 공급한다. 첫 보스인 `몽당연필 기사단장`도 불 속성 `움결` 언령결 제작 동선을 위해 이 규칙을 따른다.
- 중반 보스부터는 `돌: 말문 조각` 공급량이 늘고, 상위 보스는 `돌: 깃듦 조각`과 핵심 `먹`의 공급처 역할을 맡는다.

### 4.0. MVP 보스 기본 수치 기준
첫 보스 검증은 `몽당연필 기사단장` 1체를 기준으로 설계한다.

| 항목 | 값 | 메모 |
| :--- | :--- | :--- |
| 기준 보스 | `몽당연필 기사단장` | 첫 보스 상대 |
| 체력 | `2200` | 치명타와 언령을 감안해도 보스전 체감이 유지되도록 상향 |
| 기본 방어력 | `60` | 평상시 정직하게 치면 잘 안 깎인다 |
| 기본 피해 | `42` | 몇 대는 버티지만 무시하면 위험 |
| 이동 속도 | `38px/초` | 느리지만 압박감 있게 접근 |
| 감지 거리 | `260px` | 보스전 시작 감각용 |
| 근접 사거리 | `44px` | 플레이어보다 약간 넓은 근접 범위 |
| 공격 모션 길이 | `1.8초` | 큰 예고 동작이 보여야 한다 |
| 공격 발생 시점 | `620ms` | 읽고 회피할 틈을 줌 |
| 피격 경직 | `80ms` | 일반/정예보다 훨씬 짧다 |
| 경직 저항 | `60%` | 무한 경직 방지 |
| 약점 노출 시간 | `4초` | 파훼 창 |
| 그로기 시간 | `10초` | 화력 보상 구간 |

- 보스는 `정예보다 체력이 크게 높고`, `경직 저항`이 분명해야 한다.
- 평상시에는 오래 걸리지만, 약점 노출과 그로기 구간에서 확실히 깎이는 구조여야 한다.
- MVP 기준 플레이어 기본 방어력 `12`에 보스 기본 피해 `42`를 적용하면 일반 피격은 약 `37` 수준이며, 대검은 추가 방어 보상으로 약 `34` 수준까지 낮아진다.
- MVP 대검의 `24~32`는 피해 계수 적용 전 범위, `34.8~46.4`는 비치명타 방어력 계산 전 범위이며, 기본 치명타를 반영한 평균 기대 피해는 방어력 적용 전 `41.615`다. 보스 기본 방어력 `60`과 평상시 피해 배율 `0.5`를 차례로 적용한 평상시 최종 피해 기대값은 `13.005`다. 보스의 현재 체력 `2200`과 약점 노출/그로기 주기는 고정 처치 타수로 단정하지 않고, 첫 서버 전투 테스트의 관측 처치 시간을 바탕으로 플레이테스트 보정한다.

### 4.1. 아르카디아 던전 보스: 몽당연필 기사단장 (The Stubby Knight)
`흑심 채굴장`의 최종 보스다. 첫 수직 슬라이스에서는 축약형 채굴장 끝의 보스방 인스턴스에서 만난다.
- **외형:** 부서진 문자 갑주와 금속 파편으로 뒤엉킨 거대한 기사형 잔해.
- **전투 기믹:** 
  - **[단단한 심]:** 평상시에는 모든 물리/마법 데미지가 50% 감소합니다.
  - **[파훼법]:** 보스가 특정 타이밍에 '불'을 두려워하는 모션을 취합니다. 이때 플레이어가 [화염] 속성 언령결을 장착한 상태로 근접 타격을 적중시키면 `약점 노출` 상태가 열리고, 이 상태에서는 화염 언령이 확정 발동하여 흑연(연필심)이 타버리며 10초간 방어력이 0이 되는 '그로기' 상태에 빠집니다.
  - **MVP 수치:** 체력 `2200`, 기본 방어력 `60`, 기본 피해 `42`, 이동 속도 `38px/초`, 공격 모션 `1.8초`, 공격 발생 시점 `620ms`, 약점 노출 `4초`, 그로기 `10초`

### 4.2. 드라실 던전 보스: 망각의 잉크 드래곤 (Dragon of Oblivion)
`드라실` 구역 던전 `먹빛 서고`의 최종 보스다.
- **외형:** 먹빛 에너지와 붕괴된 문자 조각이 얽혀 만들어진 거대한 용형 침식체.
- **전투 기믹 (레이드 튜토리얼):**
  - **[글자 삼키기]:** 드래곤이 포효하며 플레이어 무기에 장착된 언령결 1개의 발동 판정을 잠시 봉쇄합니다.
  - **[정화의 언령]:** 드래곤의 머리 위에 `[ ] + [ ] + [ ]` 빈칸이 생깁니다. 보스가 지정한 주제에 맞는 `자형` 또는 `진언결`을 장착한 상태로 일정 횟수 이상 공격을 적중시키면 무력화됩니다.

### 4.3. 보스별 속성 파밍 축
- `몽당연필 기사단장`: 불 메인, 땅 보조, 초반 `돌: 새김` 공급, 불 속성 `움결` 언령결 제작용 `돌: 말문` 저확률·`돌: 말문 조각` 누적 공급. 단, 첫 수직 슬라이스의 드랍 계약(fixture)은 `돌: 새김`까지만 포함하며 `돌: 말문` 라인은 언령결 제작이 열리는 후속 범위에서 추가한다.
- `망각의 잉크 드래곤`: 어둠 메인, 불/빛 보조, `돌: 말문 조각` 입문 공급
- `서릿발 계열 보스`: 물 메인, 빛 보조, 제어형 빌드 파밍
- `성벽/거신 계열 보스`: 땅 메인, 어둠 보조, 방어형 빌드 파밍
- `폭풍/추적자 계열 보스`: 바람 메인, 빛 보조, 후반 `돌: 깃듦 조각` 진입
- `여명/심연 계열 보스`: 빛 또는 어둠 메인, 상위 `먹`과 종결 빌드 재료 공급

### 4.3.1. 보스별 속성 `음` 예시 표
| 보스 | 메인 속성 | 보조 속성 | 메인 `음` 예시 | 보조 `음` 예시 | 메모 |

| `서릿발 서고 수호자` | 물 | 빛 | `ㅁ`, `ㅜ`, `ㄹ`, `ㅅ` | `ㅂ`, `ㅣ`, `ㅊ` | 제어형, 냉기/정화 계열 재료 |
| `붕괴한 성벽 거신` | 땅 | 어둠 | `ㄷ`, `ㅏ`, `ㅇ`, `ㄱ` | `ㅇ`, `ㅓ`, `ㄷ`, `ㅜ`, `ㅁ` | 방어형 빌드용 파밍 축 |

- 표의 `음`은 대표 예시이며, 실제 드랍은 같은 속성 계열의 다른 `음`과 섞여 나올 수 있다.
- 메인 속성 `음`은 `보통~높음`, 보조 속성 `음`은 `낮음~보통` 빈도로 드랍하는 방향을 기준으로 한다.
- 같은 보스를 반복 공략하면 특정 속성 `자형`, `결: 글자`, 진언결, 언령결 제작 재료가 자연스럽게 모이도록 설계한다.
- 보스의 기믹, 외형, 드랍 속성은 서사적으로 같은 축을 공유해야 한다.

## 5. 피격 및 타격 연출 (Combat Feedback)
- **타격감:** 단일 대상 언령결이 적중할 때 짧고 강한 화면 흔들림(Screen Shake), 관통감 있는 이펙트, 응축된 히트 사운드를 사용합니다.
- **드랍 연출:** 몬스터 처치 시 골드와 `음`이 분수처럼 포물선을 그리며 바닥에 쏟아지고(Loot Explosion), `음`은 각자의 고유한 색상으로 은은하게 빛납니다.
