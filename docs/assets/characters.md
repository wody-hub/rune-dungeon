# 캐릭터 에셋 기록

캐릭터 원화, 이미지 생성 후보, Blender 원본, GLB의 출처와 승인 상태를 기록한다. 외부 생성형 서비스를 새로 사용하면 생성 시점의 비용·공개 정책·라이선스를 확인해 정확한 출처 문구를 남긴다.

## 상태값

- `후보`: 검토 중이며 게이트 입력으로 아직 승인되지 않음
- `승인`: 해당 게이트에서 확정되어 다음 단계의 입력으로 사용 가능
- `미사용`: 보존은 하지만 더 이상 제작 입력이나 런타임 에셋으로 사용하지 않음

## 갱신 규칙

- 기존 파일을 덮어쓰지 않는다. 수정본은 새 `vNN` 파일로 추가하고, 이전 파일 상태를 `미사용`으로 바꾼다.
- A1 또는 A2를 승인할 때는 이 표에 승인 날짜와 승인 근거를 남긴다.
- 게이트 B 이후에는 Meshy/Tripo 결과물, Blender 원본, Mixamo 애니메이션 출처, 최종 GLB까지 같은 표에서 추적한다.
