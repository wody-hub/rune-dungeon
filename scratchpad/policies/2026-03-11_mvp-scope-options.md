# MVP 포함/제외 초안

## 목적
초기 개발 범위를 강제로 줄여 실제 제작 가능한 게임으로 재구성한다.

## 반드시 포함
- 플레이어 이동, 공격, 피격, 적 처치
- 1개 던전 테마
- 1개 일반 몬스터군 + 1개 보스
- 자모 파편 드랍
- 글자 룬 조합
- 장비 1부위 이상 장착 시스템
- 룬 장착 또는 단순 패시브 효과
- 기본 인벤토리
- 기초 성장 수치 (레벨 또는 장비 강화 중 하나)
- 튜토리얼 흐름

## 포함 권장
- 의미 발현이 있는 희귀 글자 몇 개
- 단어 룬 2~5개
- 속성 3종 이하
- 보스 약점 기믹 1개
- 간단한 허브 화면

## 보류 권장
- 자동 사냥
- 오프라인 펫 파밍
- 거래소
- 하우징
- 멀티플레이 레이드
- 장비 추출/보존 룬
- 품질 70% 이상 파괴
- 문장형 언령 도감
- 8단계 승급
- 천지인 각성
- 광고 시스템

## 제거 검토
- 2년 단위 만렙 설계
- 어린이 대상과 하드코어 대상의 동시 메인 타깃
- 모든 플랫폼 동시 최적화 전제

## MVP 예시 정의
플레이어는 던전에서 몬스터를 처치해 자모 파편을 수집하고, 이를 조합해 글자 룬을 만들고, 장비에 장착해 더 강한 적과 1층 보스를 공략한다.

## 현재 선택 반영 메모
- MVP는 `하이브리드` 방향을 따른다.
- 자동/방치 루프를 초기에 포함한다.
- 수동 던전도 초기부터 포함하되, 콘텐츠 규모는 작게 시작한다.
- 권장 구조:
  - 자동/방치: 기본 파편, 골드, 경험치 수급
  - 수동 던전: 보스 재료, 희귀 글자, 특수 강화 재료 수급
