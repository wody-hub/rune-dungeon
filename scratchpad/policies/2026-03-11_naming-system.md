# 네이밍 체계 초안

## 목적
한글 조합과 상위 제작 시스템의 용어를 통일한다.

## 핵심 원칙
- `조합`과 `각인`은 다른 단계다.
- `조합`은 글자를 만드는 행위다.
- `각인`은 글자 조합물을 전투/장비용 룬으로 확정하는 행위다.

## 용어 정의

### 1. 자형
- 자모 파편을 `100% 확정 조합`해 만든 글자의 형태
- 예: `자형: 강`, `자형: 불`, `자형: 빛`
- 역할: 초반 직접 장착용 기초 아이템이자 상위 `결` 제작 재료

### 2. 결: 글자
- `자형` 중 의미가 허용된 글자에 `각인`을 거쳐 완성한 아이템
- 예: `결: 강`
- 역할: 의미가 부여된 단일 글자 결, 상위 제작 재료 또는 단독 장착용 고급 아이템

### 3. 진언 룬
- 여러 글자 룬을 조합한 뒤 `각인`해서 완성하는 단어형 룬
- 역할: 패시브, 장비 효과, 룬워드 계열
- 예: `태양`, `강화`, `신속`

### 4. 언령 룬
- 여러 글자 룬을 조합한 뒤 `각인`해서 완성하는 문장형 룬
- 역할: 액티브 스킬, 주문, 마법서 등록 대상
- 예: `어둠을 밝히는 불꽃이여`

### 5. 각인
- 글자 조합 결과를 최종 룬으로 승격시키는 제작 행위
- UI 버튼/메뉴 명칭으로 사용 가능
- 예: `진언 각인`, `언령 각인`

### 6. 각인 촉매
- 각인을 수행할 때 필요한 특수 재료의 총칭
- 예시 세부 아이템:
  - `진언 각인석`
  - `언령 각인석`

### 7. 인
- 캐릭터의 몸에 새겨 속성 정체성과 변신 계열을 여는 각성 재료
- 예:
  - `인: 움결 화`
  - `인: 무늬 수`
  - `인: 물결 지`
  - `인: 울림 풍`
  - `인: 빛살 광`
  - `인: 온결 암`

## 제작 단계 구조
- `자모 조합` -> `자형 생성`
- `자형 + 각인` -> `결: 글자`
- `자형 또는 결: 글자 조합 + 각인 촉매` -> `진언 룬`
- `자형 또는 결: 글자 문장 조합 + 각인 촉매` -> `언령 룬`
- `인 각인` -> `캐릭터 속성 및 변신 계열 확정`

## 문서 표현 원칙
- `조합`은 `자형` 생성에만 사용한다.
- `결`은 의미가 각인된 완성 아이템에만 사용한다.
- 단어/문장 기반 상위 룬 생성은 `각인`으로 표기한다.
- `의미 부여`는 내부 설명 문장에서는 사용할 수 있으나, 시스템 명칭으로는 사용하지 않는다.

## 추천 UI 문구
- 메뉴명:
  - `자형 제조`
  - `각인`
- 버튼명:
  - `자형 합성`
  - `진언 각인`
  - `언령 각인`
- 설명문:
  - `자모 파편을 조합해 자형을 제조할 수 있습니다. 자형 제조는 100% 성공합니다.`
  - `의미가 허용된 자형에는 결 각인을 진행할 수 있습니다.`
  - `정해진 글자 조합에 각인 촉매를 사용하면 진언 룬을 제작할 수 있습니다.`
  - `정해진 문장 조합에 각인 촉매를 사용하면 언령 룬을 제작할 수 있습니다.`
