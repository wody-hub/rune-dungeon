# 네이밍 체계 초안

## 목적
한글 조합과 상위 제작 시스템의 용어를 통일한다.

## 핵심 원칙
- `조합`과 `각인`은 다른 단계다.
- `조합`은 글자를 만드는 행위다.
- `각인`은 글자 조합물을 전투/장비용 룬으로 확정하는 행위다.

## 용어 정의

### 1. 글자 룬
- 규칙 기반 조합으로 만든 1차 결과물
- 예: `강`, `불`, `빛`
- 역할: 상위 제작의 기본 재료이자 일부 단독 장착 가능 룬

### 2. 진언 룬
- 여러 글자 룬을 조합한 뒤 `각인`해서 완성하는 단어형 룬
- 역할: 패시브, 장비 효과, 룬워드 계열
- 예: `태양`, `강화`, `신속`

### 3. 언령 룬
- 여러 글자 룬을 조합한 뒤 `각인`해서 완성하는 문장형 룬
- 역할: 액티브 스킬, 주문, 마법서 등록 대상
- 예: `어둠을 밝히는 불꽃이여`

### 4. 각인
- 글자 조합 결과를 최종 룬으로 승격시키는 제작 행위
- UI 버튼/메뉴 명칭으로 사용 가능
- 예: `진언 각인`, `언령 각인`

### 5. 각인 촉매
- 각인을 수행할 때 필요한 특수 재료의 총칭
- 예시 세부 아이템:
  - `진언 각인석`
  - `언령 각인석`

## 제작 단계 구조
- `자모 조합` -> `글자 룬 생성`
- `글자 룬 조합 + 각인 촉매` -> `진언 룬`
- `글자 룬 문장 조합 + 각인 촉매` -> `언령 룬`

## 문서 표현 원칙
- `조합`은 글자 생성에만 사용한다.
- 단어/문장 기반 상위 룬 생성은 `각인`으로 표기한다.
- `의미 부여`는 내부 설명 문장에서는 사용할 수 있으나, 시스템 명칭으로는 사용하지 않는다.

## 추천 UI 문구
- 메뉴명: `각인`
- 버튼명:
  - `진언 각인`
  - `언령 각인`
- 설명문:
  - `정해진 글자 조합에 각인 촉매를 사용하면 진언 룬을 제작할 수 있습니다.`
  - `정해진 문장 조합에 각인 촉매를 사용하면 언령 룬을 제작할 수 있습니다.`
