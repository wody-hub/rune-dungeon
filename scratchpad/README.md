# Scratchpad

임시 검토, 충돌 분석, 해결안 후보, 보류안, 재정의 메모를 두는 작업 공간.

권장 사용 규칙:
- 확정된 내용은 `plan/`으로 이동한다.
- 아직 결정되지 않은 내용은 여기서만 관리한다.
- 파일명은 `YYYY-MM-DD_주제.md` 형태를 우선 사용한다.
- 문서 상단에 상태를 적는다. 예: `Status: draft`, `Status: review`, `Status: merged`, `Status: discarded`

추천 문서 예시:
- `2026-03-11_product-direction-conflicts.md`
- `2026-03-11_mvp-scope-options.md`
- `2026-03-11_tone-and-target-decisions.md`
