# 진언/언령 콘텐츠 수량 및 사용 구조 설계

## 목적
티어별 콘텐츠 수량을 통제하고, 언령의 상위 티어 사용이 하위 티어와 연결되도록 성장 구조를 정의한다.

## 핵심 결론
- 진언은 각 티어마다 `최대 5개` 수준으로 제한한다.
- 언령은 `움결`, `무늬`에서 각 속성 라인마다 `3개`씩 운영하고, `물결` 이후 각 티어마다 `속성별 1개`를 기본 원칙으로 한다.
- 상위 티어 언령은 단독 해금형이 아니라, `하위 티어 언령을 함께 사용하는 연계 구조`로 설계한다.

## 진언 수량 원칙

### 기본 원칙
- 각 티어당 진언은 `약 5개`를 목표로 한다.
- 5개를 초과하더라도 예외는 최소화한다.
- 역할이 겹치는 진언은 만들지 않는다.

### 의도
- 선택지를 주되 과도한 조합 피로를 막는다.
- 각 티어의 대표 진언이 기억 가능해야 한다.
- 자동/방치 중심 게임에서도 빌드 이해가 쉬워야 한다.

### 권장 역할 구성
- 공격 강화형
- 속도/회전율형
- 생존형
- 속성 특화형
- 특수 시너지형

### 역할별 옵션 고정
- 공격 강화형:
  - `데미지 % 증가`
  - `치명타 확률 증가`
  - `치명타 피해 증가`
- 속도/회전율형:
  - `공격 속도 증가`
  - `이동 속도 증가`
  - `스킬 쿨타임 감소`
- 생존형:
  - `받는 스턴 시간 감소`
  - `받는 스턴 확률 감소`
- 속성 특화형:
  - `속성 공격력 % 증가`
- 특수 시너지형:
  - `스턴 확률 증가`

## 언령 수량 원칙

### 기본 원칙
- `움결`, `무늬`는 각 속성 라인마다 `3개`
- `물결` 이후 6대 속성 기준이면 티어당 언령은 최대 `6개`
- 필요 시 무속성/공용 언령은 별도 예외로 둘 수 있으나, 초기에는 최소화

### 의도
- 액티브 스킬 수를 강하게 통제한다.
- 티어가 올라갈수록 속성별 대표 스킬이 진화하는 느낌을 만든다.
- 스킬 기획과 밸런싱 범위를 관리 가능한 수준으로 유지한다.

## 언령 연계 사용 구조

### 핵심 원칙
- 상위 티어 언령은 하위 티어 언령과 단절되지 않는다.
- 강한 언령 하나만 바꿔 끼우는 구조보다, 누적 성장의 느낌을 주어야 한다.

### 추천 구조
- 상위 티어 언령을 사용하려면, 같은 속성의 하위 티어 언령을 이미 보유하거나 장착해야 한다.
- 일부 상위 언령은 하위 언령 사용 이력 또는 선행 각인을 요구할 수 있다.
- 전투에서는 상위 언령만 쓰는 것이 아니라, 하위 언령도 함께 쓰는 로테이션을 유도한다.

### 구현 방향 예시
- `결` 화염 언령 사용 가능
- `무늬` 화염 언령 해금 시 `결` 화염 언령 보유 필요
- `물결` 화염 언령은 `결 + 무늬` 화염 언령 각인 완료 상태 필요

## 언령 딜레이 및 연쇄 구조

### 기본 개념
- 상위 티어 언령일수록 강하지만 준비 시간이 있거나 사용 조건이 더 있다.
- 낮은 티어 언령은 즉응성, 상위 티어 언령은 결정력 역할을 맡는다.

### 추천 방식
- 낮은 티어 언령:
  - 짧은 시전 시간
  - 짧은 쿨타임
  - 약한 효과
- 높은 티어 언령:
  - 더 긴 시전 시간 또는 준비 동작
  - 더 긴 쿨타임
  - 강한 효과
  - 하위 티어 언령과의 연계 조건

### 전투 사용 예시
- 낮은 티어 화염 언령으로 점화 상태 부여
- 중간 티어 화염 언령으로 범위 확장
- 상위 티어 화염 언령으로 폭발/마무리

## 기대 효과
- 초반 언령이 후반에 완전히 버려지지 않는다.
- 스킬 수는 적지만 성장 체감은 크게 만들 수 있다.
- 속성 빌드의 정체성이 분명해진다.
- 상위 언령만 뽑으면 끝나는 구조를 피할 수 있다.

## 천지인 각성 연계

### 기본 원칙
- `근원의 나라`에서 획득하는 `천지인` 재료는 기존 언령을 대체하지 않는다.
- 대신 이미 보유한 `낮은 티어 언령`을 강화하는 데 사용한다.

### 강화 방향
- 기존 낮은 티어 언령의 성능을 상향
- 이펙트 규모와 시각 효과 강화
- 특정 조건에서 상위 티어 언령과의 연계 효과 추가 가능

### 의도
- 초반에 얻은 언령이 후반에도 완전히 폐기되지 않도록 한다.
- 후반 콘텐츠인 `근원의 나라`가 기존 빌드의 재해석과 확장 구간이 되게 한다.
- 천지인은 단순 상위 스킬 해금 재료가 아니라, `기존 힘을 다시 깨우는 각성 재료`로 사용한다.

### 예시
- `움결` 티어 화염 언령에 천지인을 사용하면:
  - 화염 범위 증가
  - 점화 지속시간 증가
  - 시전 이펙트가 상위 단계로 변화
- `무늬` 티어 빙결 언령에 천지인을 사용하면:
  - 빙결 확률 또는 지속시간 증가
  - 피격 연출과 장판 시각 효과 강화

### 설계상 장점
- 낮은 티어 언령의 장기 보존 가치 확보
- 후반 파밍이 과거 콘텐츠를 되살리는 구조 형성
- 언령 수량을 늘리지 않고도 성장감 확장 가능

## 주의사항
- 연계 조건이 너무 복잡하면 자동/방치 중심 흐름과 충돌할 수 있다.
- 따라서 실제 전투 입력은 단순해야 한다.
- 연계는 `획득/장착 조건` 또는 `부가 효과 조건`으로 구현하고, 과도한 입력 콤보는 피하는 편이 안전하다.

## 추천 세부 기준

### 진언
- 티어당 `5개` 전후
- 각 티어 대표 빌드 역할을 나눠 갖는다.
- 역할 정의는 `공격`, `속도`, `생존`, `속성`, `특수` 5축으로 고정한다.

### 언령
- `움결`, `무늬`: 각 속성 라인마다 `3개`
- `물결` 이후: 티어당 `속성별 1개`
- 상위 티어 언령은 같은 속성의 하위 티어 언령 선행 요구
- 상위 티어일수록 시전 시간과 위력 증가

## 다음 설계로 연결할 내용
- 6대 속성별 언령 계보 표
- 티어별 진언 5종 역할 고정
- 하위 언령 선행 조건의 정확한 규칙
- 자동 전투에서 언령 로테이션 처리 방식
