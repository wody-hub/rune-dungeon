# 보스/던전 유형별 세부 드랍 기대값 표

## 목적
던전 1회, 일일 플레이, 주간 플레이 기준의 보상 기대값을 정의해 파밍 속도와 제작 진입 속도가 과하거나 막히지 않는지 검토한다.

## 전제
- 이 문서는 `확률표`가 아니라 `기대값 기준 운영 초안`이다.
- 실제 구현 시에는 ±10~20% 조정 가능성을 열어둔다.
- 평균 숙련 유저 기준으로 `일일 수동 4~8회`, `주간 핵심 던전 20~40회` 정도를 상정한다.
- 자동/방치는 별도의 누적 축으로 작동하며, 수동 기대값을 완전히 대체하지 않는다.

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

| 엘리트 던전 1회 | `6~10개` | `5~8개` | `1~2개` | 없음 | `돌: 새김 0.6~0.8개`, `돌: 말문 조각 0.2~0.4개` | `남김 0.2개`, `돋움 0.05개` 기대 | 글자결 `20%`, 하위 진언결 `3~5%` |
| 보스 던전 1회 | `4~8개` | `4~7개` | `3~5개` | `0~1개` | `돌: 말문 조각 1~2개`, `돌: 말문 0.1~0.2개` 기대 | `남김 0.3개`, `돋움 0.1개` 기대 | 핵심 글자결 `20~30%`, 진언결 `5~8%`, 언령결 `1% 미만` |
| 특수 던전 1회 | `2~4개` | `3~5개` | `4~6개` | `1~3개` | `돌: 깃듦 조각 0.8~1.2개`, `돌: 깃듦 0.03~0.07개` 기대 | `남김 0.3개`, `돋움 0.2개`, `지킴 0.08~0.12개` | 상위 글자결 `10%`, 상위 진언결 `2~4%`, 언령결 `1% 미만` |
| 근원의 나라 1회 | 없음 | `2~4개` | `2~4개` | `1~2개` | `돌: 깃듦 0~0.05개` 기대 | 상위 `돋움 0.15개`, `지킴 0.1개` 기대 | 없음, 대신 `천지인 1~2개` |

## 일일 권장 플레이 기준 기대값

### 일반 던전 4회
- 공용 기본 파편 `40~64개`
- 중급 파편 `8~20개`
- `돌: 새김` 약 `1~2개`
- 하위 글자결 `0~1개`

### 엘리트 던전 4회
- 중급 파편 `20~32개`
- 희귀 파편 `4~8개`
- `돌: 새김` 약 `2~3개`
- `돌: 말문 조각` 약 `1개`
- `남김` 기대치 약 `1개`

### 보스 던전 4회
- 희귀 파편 `12~20개`
- 특정 속성 파편 `4~8개`
- `돌: 말문 조각 4~8개`
- `돌: 말문` 완제품 기대치 `0.4~0.8개`
- `남김` `1개` 전후, `돋움` `0~1개`

### 특수 던전 4회
- 희귀 파편 `16~24개`
- 특수 파편 `4~12개`
- `돌: 깃듦 조각 3~5개`
- `돌: 깃듦` 완제품 기대치 `0.1~0.3개`
- `지킴` 기대치 `0.3~0.5개`

## 주간 누적 기대값 초안

| 콘텐츠 | 주간 권장 횟수 | 핵심 누적 기대 |
| :--- | :--- | :--- |
| 일반 던전 | `12~20회` | `돌: 새김 4~8개`, 하위 글자결 안정 수급 |
| 엘리트 던전 | `12~20회` | `돌: 새김 8~12개`, `돌: 말문 조각 3~6개`, 희귀 파편 안정화 |
| 보스 던전 | `12~16회` | `돌: 말문 조각 12~32개`, `돌: 말문 1~3개`, `남김 3~5개`, `돋움 1~2개` |
| 특수 던전 | `8~12회` | `돌: 깃듦 조각 8~14개`, `돌: 깃듦 0~1개`, `지킴 1개` 전후 |
| 근원의 나라 | `4~8회` | `천지인 4~16개`, 상위 `먹` 보조 수급 |

## 돌 기대값 검증

### `돌: 말문`
- 조각 교환 비율: `8개 -> 1개`
- 보스 1회 기대: `1~2개`
- 해석:
  - 평균적으로 `4~8회`면 `돌: 말문 1개` 확보 가능
  - `결`, `무늬`는 진입이 무리 없고
  - `물결` 이후부터는 반복 플레이가 체감되기 시작함

### `돌: 깃듦`
- 조각 교환 비율: `15개 -> 1개`
- 특수 던전 1회 기대: `0.8~1.2개`
- 해석:
  - 평균적으로 `12~15회` 내외면 `돌: 깃듦 1개` 확보 가능
  - 완제품 드랍이 뜨면 파밍 주기가 크게 단축됨
  - `숨결` 이상 티어의 장기 목표로 적합

## 티어 구간별 파밍 체감

| 티어 | 주력 콘텐츠 | 주간 기대 감각 |
| :--- | :--- | :--- |
| `움결` | 일반 던전 + 초반 보스 | 일주일 내 언령 1~2회 시도 가능 |
| `무늬` | 엘리트 + 보스 | 희귀 파편과 `말문 조각`이 동시에 쌓이는 구간 |
| `물결` | 보스 중심 | `말문` 누적 파밍이 본격적으로 체감됨 |
| `울림` | 보스 + 특수 던전 입문 | `돋움`, `깃듦 조각`의 가치가 보이기 시작 |
| `숨결` | 보스 + 특수 던전 | `말문`보다 `깃듦`, `지킴` 확보가 핵심 목표 |
| `빛살` | 특수 던전 중심 | 특수 파편과 `지킴`이 제작 체감의 중심 |
| `여울` | 특수 던전 + 근원의 나라 | 장기 누적 보장 구조가 핵심 |
| `온결` | 특수 던전 + 근원의 나라 | 짧은 주기 성취보다 시즌급 목표에 가까움 |

## 위험 신호 체크

### 너무 빠른 경우
- `움결 ~ 무늬` 언령결이 하루 단위로 과도하게 쌓임
- `돌: 말문 조각`이 보스 2~3회만에 완제품으로 환산됨
- `지킴결`이 주간 3개 이상 안정 공급됨

### 너무 느린 경우
- `물결` 언령결 1회 시도에 일주일 이상 소요됨
- `돌: 깃듦` 1개 확보에 20회 이상 반복이 필요함
- `숨결` 이후 티어에서 `먹` 부족으로 시도 자체가 막힘

## 현재 초안의 해석
- `움결 ~ 무늬`는 진입 장벽이 낮고 학습 루프가 잘 유지된다.
- `물결 ~ 울림`은 보스 던전 반복의 보상이 분명하다.
- `숨결 ~ 온결`은 특수 던전과 `먹` 수급이 실질적인 메인 콘텐츠가 된다.
- 자동/방치는 계속 의미가 있지만, 상위 재료를 대체하지는 못한다.
