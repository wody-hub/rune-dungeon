# 티어별 허용 글자 수 기준

## 목적
같은 티어 내 진언결/언령결의 이름 길이를 일정 범위로 맞춰 제작 난이도 편차를 줄인다.

## 핵심 원칙
- 같은 티어의 결은 `글자 수`가 지나치게 벌어지지 않아야 한다.
- 실제 난이도는 글자 수 + 희귀/특수 파편 비율로 결정되므로, 글자 수는 먼저 상한선을 맞춘다.
- 이름 길이 기준은 이후 실제 글자 조합과 파편 요구량 설계의 검수 기준이 된다.

## 진언결 글자 수 기준

| 티어 | 권장 글자 수 |
| :--- | :--- |
| `씨앗` | `1자` |
| `결` | `2자` |
| `무늬` | `2자` |
| `물결` | `2자` |
| `울림` | `2자` |
| `숨결` | `2자` |
| `빛살` | `2자` |
| `여울` | `2자` |
| `온결` | `2자` |

## 언령결 글자 수 기준

| 티어 | 권장 글자 수 범위 |
| :--- | :--- |
| `씨앗` | 미도입 또는 `3~4자` |
| `결` | `6~8자` |
| `무늬` | `8~10자` |
| `물결` | `10~12자` |
| `울림` | `12~14자` |
| `숨결` | `14~16자` |
| `빛살` | `14~16자` |
| `여울` | `16~18자` |
| `온결` | `16~18자` |

## 진언결 검수 메모
- 현재 초안은 대부분 기준에 맞음
- `씨앗` 티어는 1자 원칙과 잘 맞음
- 이후 실제 글자 조합 확정 단계에서 희귀 파편 비율만 추가 검증하면 됨

## 언령결 검수 메모
- 현재 초안은 같은 티어 안에서도 길이 편차가 큼
- 특히 `숨결`, `빛살`, `온결` 티어에서 문장 길이 통제가 필요함
- 다음 단계에서 각 언령결 이름을 권장 범위에 맞게 다듬는 작업이 필요함

## 설계 의도
- 유저가 같은 티어의 다른 속성 언령결을 제작할 때 체감 난이도가 과도하게 벌어지지 않게 한다.
- 수동 던전의 가치가 글자 수 격차가 아니라 희귀 재료 격차에서 나오게 만든다.

- 현재 언령결 이름표에 글자 수 표시 추가
- 권장 범위를 벗어나는 이름 다듬기
