# 자동/방치와 수동 던전의 보상 분담 설계

## 목적
자동/방치 중심 구조를 유지하면서도 수동 던전이 메인급 가치를 갖도록 보상 구조를 정의한다.

## 핵심 결론
- 자동/방치는 `기본 재화와 룬 파편의 장기 누적 수급`을 담당한다.
- 수동 던전은 `같은 제작 축을 더 빠르게 밀어주는 고효율 수급`을 담당한다.
- 진언, 언령, 승급 재료도 본질적으로는 `룬 파편 기반 제작`으로 통일한다.
- 하위 등급의 진언/언령은 제작 확률이 높고, 상위 등급으로 갈수록 제작 확률이 크게 낮아진다.
- 수동 던전은 이 낮은 확률 구간을 우회하거나 완화하는 보상을 제공한다.

## 모드별 역할 정의

### 1. 자동/방치
- 장기 접속 유지와 누적 성장의 중심
- 플레이 시간이 적은 유저도 기본 성장 가능
- 기본 재화와 일반 파편의 꾸준한 공급원

### 2. 수동 던전
- 집중 플레이 보상과 성장 가속의 중심
- 자동과 동일한 제작 축을 공유하지만 기대값이 더 높음
- 상위 제작에 필요한 희귀 재료, 고등급 파편, 완성 룬 직드랍 가능성 제공

## 보상 구조 원칙

### 공통 원칙
- 최종적으로 필요한 대부분의 콘텐츠는 `룬 파편 기반 제작`으로 연결된다.
- 자동과 수동은 보상 종류를 완전히 분리하지 않는다.
- 대신 `수급 효율`, `희귀도`, `실패 리스크 완화`에서 차이를 둔다.

### 자동/방치 보상
- 골드
- 경험치
- 일반 자모 파편
- 하위 제작용 보조 재화
- 낮은 확률의 중급 파편

### 수동 던전 보상
- 골드
- 경험치
- 일반 자모 파편
- 중급/고급 룬 파편
- 특정 속성 파편
- 희귀 글자 룬 직접 드랍 확률
- 각인 촉매 드랍 확률
- 제작 실패 보호 재료 또는 확률 보정 재료

## 제작 단계와 연결 방식

### 1. 글자 룬 제작
- 자모 파편을 모아 규칙 기반 조합으로 `글자 룬` 생성

### 2. 진언 룬 제작
- 필요한 글자 룬을 모은 뒤 `각인 촉매`를 사용해 `진언 룬` 제작
- 제작 성공률은 진언 등급에 따라 차등 적용

### 3. 언령 룬 제작
- 필요한 글자 룬을 모은 뒤 `각인 촉매`를 사용해 `언령 룬` 제작
- 제작 성공률은 언령 등급에 따라 차등 적용

### 4. 승급 재료 제작
- 승급용 특수 룬 또는 재료도 파편 기반으로 연결
- 상위 승급 재료일수록 희귀 파편과 낮은 성공률 요구

## 확률 설계 원칙

### 하위 등급
- 제작이 비교적 쉬워야 함
- 초반 진언/언령은 높은 성공률로 접근성을 확보

### 중위 등급
- 반복 플레이를 요구하되 과도한 좌절은 피함
- 자동만으로도 도달 가능하지만 시간이 더 오래 걸림

### 상위 등급
- 제작 성공률이 매우 낮을 수 있음
- 예시 기준: `5%` 수준까지 허용
- 이 구간에서 수동 던전은 강한 가치 제공

## 수동 던전의 메인급 가치 확보 방법

### 1. 상위 파편 수급 우위
- 자동보다 높은 빈도로 중급/고급 파편 획득

### 2. 완성 룬 직접 드랍 우위
- 낮은 확률이지만 진언/언령 제작에 필요한 핵심 글자 룬 완제품 드랍 가능

### 3. 각인 촉매 공급
- 진언 각인석
- 언령 각인석
- 상위 각인 보조 재료

### 4. 실패 리스크 완화
- 제작 보호 재료
- 성공률 보정 재료
- 특정 등급 제작 전용 촉매

## 자동/수동 관계 정의
- 자동은 `누적 성장`
- 수동은 `성장 가속`
- 자동만으로도 대부분의 목표에 도달 가능해야 한다.
- 수동은 상위 제작과 고등급 접근성을 크게 앞당겨야 한다.
- 두 모드는 경쟁이 아니라 상호 보완 구조여야 한다.

## 주의사항
- 수동이 단순히 `더 많이 준다`만 되면 숙제화될 수 있다.
- 따라서 수동은 양적 우위뿐 아니라 `질적 우위`도 가져야 한다.
- 질적 우위 예시:
  - 상위 파편
  - 완성 룬 직드랍
  - 각인 촉매
  - 실패 보호 재료

## 현재 기준 설계 문장
`자동/방치는 기본 재화와 룬 파편의 장기 누적 수급을 담당하며, 수동 던전은 동일한 제작 축 위에서 상위 파편, 각인 촉매, 완성 룬 직드랍을 통해 고등급 진언/언령 제작을 가속하는 역할을 맡는다.`

## 다음 상세 설계로 연결할 주제
- 룬 파편 희귀도 표
- 각인 촉매 종류와 획득처
- 진언/언령 등급별 제작 성공률 표
- 자동/수동 콘텐츠별 드랍 테이블
