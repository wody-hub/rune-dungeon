# Design Drafts

정책서(`scratchpad/policies/`)를 기반으로 작성하는 상세 설계 초안 공간.

## 설계 순서 권장
1. 정책 문서 확인
2. 대상 시스템 1개 선택
3. 상태, 데이터, 규칙, UI 흐름, 예외 처리 정의
4. 초안을 검토한 뒤 `plan/` 반영 여부 결정

## 권장 설계 문서 예시
- 자동/방치 보상 구조 설계
- 수동 던전 보상 구조 설계
- 글자 룬 조합 및 각인 플로우 설계
- 진언 룬/언령 룬 데이터 구조 설계
- 인벤토리 및 아이템 타입 설계
