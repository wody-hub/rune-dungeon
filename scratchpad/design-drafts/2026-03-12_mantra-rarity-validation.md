# 진언결 희귀도 비율 교차 검증

## 목적
진언결 실제 자모 구성이 티어별 파편 희귀도 목표와 맞는지 검증하고, 보정이 필요한 이름을 식별한다.

## 기준 문서
- `2026-03-12_fragment-rarity-table.md`
- `2026-03-12_mantra-composition-table.md`
- `2026-03-12_mantra-jamo-breakdown.md`

## 검증 방식
- 각 티어의 진언결 5개를 기준으로 자모 희귀도 경향을 본다.
- 아직 정확한 자동 계산이 아닌 1차 정성 검수다.
- 판정 기준:
  - `적정`: 현재 티어 감각과 대체로 일치
  - `쉬움`: 목표보다 희귀/특수 자모 비중이 낮음
  - `어려움`: 목표보다 희귀/특수 자모 비중이 높음

## 티어별 목표 상기

| 티어 | 목표 방향 |
| :--- | :--- |
| `씨앗` | 기본 파편 중심 |
| `움결` | 기본 + 중급 중심 |
| `무늬` | 기본/중급 중심 + 희귀 소량 |
| `물결` | 중급 비중 상승 + 희귀 진입 |
| `울림` | 희귀 파편이 본격 핵심 |
| `숨결` | 희귀 핵심 + 특수 소량 |
| `빛살` | 희귀 중심 + 특수 진입 |
| `여울` | 희귀 중심 + 특수 확대 |
| `온결` | 희귀/특수 중심 |

## 티어별 판정

### 씨앗
- `힘`, `숨`, `불`, `결`은 초반 기준에 대체로 적합
- `빛`은 `ㅊ`이 포함되어 있어 다른 씨앗 티어보다 약간 어려울 수 있음

판정:
- 전체: `적정`
- 보정 후보: `빛`

### 움결
- `강화`, `신속`, `버팀`, `집중`은 기본/중급 중심으로 무난
- `냉기`는 `ㅐ` 포함으로 같은 티어 내에서는 살짝 어려운 편

판정:
- 전체: `적정`
- 보정 후보: `냉기`

### 무늬
- `강타`, `철벽`, `화염`, `연쇄`는 희귀 자모가 자연스럽게 섞임
- `질주`는 상대적으로 쉬운 편

판정:
- 전체: `적정`
- 보정 후보: `질주`

### 물결
- `관통`, `파동`은 희귀 진입 티어에 잘 맞음
- `비상`, `흡수`, `빙결`은 비교적 쉬움

판정:
- 전체: `약간 쉬움`
- 보정 후보: `비상`, `흡수`, `빙결`

### 울림
- `폭풍`, `섬광`, `번개`는 희귀 자모 비중이 있어 좋음
- `수호`, `공명`은 티어에 비해 쉬운 편

판정:
- 전체: `약간 쉬움`
- 보정 후보: `수호`, `공명`

### 숨결
- `태양`, `환류`는 상위 티어 감각이 있음
- `유영`, `성역`, `심연`은 이름의 상징성은 높지만 자모 희귀도는 상대적으로 낮음

판정:
- 전체: `쉬움`
- 보정 후보: `유영`, `성역`, `심연`

### 빛살
- `천뢰`, `광행`, `만개`는 적절
- `불멸`, `성운`은 자모 희귀도만 보면 상대적으로 낮음

판정:
- 전체: `적정`
- 보정 후보: `불멸`, `성운`

### 여울
- `순광`, `창세`, `회귀`는 상위 티어 감각이 강함
- `멸각`, `영겁`은 자모 희귀도 기준으로는 다소 낮음

판정:
- 전체: `적정`
- 보정 후보: `멸각`, `영겁`

### 온결
- `찰나`, `일천`, `환원`은 상위 티어 감각이 있음
- `무극`, `온전`은 이름의 위상은 높지만 자모 난이도는 상대적으로 낮음

판정:
- 전체: `약간 쉬움`
- 보정 후보: `무극`, `온전`

## 1차 결론
- 초중반 티어는 전반적으로 큰 문제 없음
- `물결` 이후부터는 이름의 위상보다 자모 희귀도가 낮은 항목이 일부 존재
- 특히 `숨결`, `온결`은 재검토가 필요

## 수정 방향 제안
- 쉬운 항목은 이름을 더 희귀 자모가 섞인 단어로 바꾸기
- 또는 추가 각인 조건, 상위 `돌: 깃듦`, 특수 파편 요구를 붙여 티어 난이도 보정
- 이름이 좋고 세계관 위상이 크다면, 자모 난이도 대신 `돌`/`먹` 요구량으로 보정하는 것도 가능
