# 인 변신 단계 정책

> 폐기된 초안(2026-08-06): 티어별 외형 단계는 사용하지 않는다. 현재 정본은 `plan/06_Art_Direction.md`, `plan/07_Item_Visual_Progression.md`, `plan/16_Character_and_Leveling.md`의 단일 메시 변신 on/off 계약이다.

## 목적
`인: [티어] [속성]`이 외형과 전투 상태에서 어떻게 읽히는지 단계별로 고정한다.

## 공통 원칙
- `인`은 속성과 티어를 함께 가진다.
- `변신`은 전투 모드, `변신 해제`는 비전투 모드다.
- 기본 상태 외형은 별도 무속성 폼이 아니라 현재 인 계열의 `1티어 외형`이다.

## 단계 구조

| 단계 | 상태 | 외형 기준 | 설명 |
| :--- | :--- | :--- | :--- |
| 1 | 비전투 기본 상태 | `1티어 외형` | 마을, 휴식, 이동 기본 상태 |
| 2 | 전투 변신 | 현재 인 티어 외형 | 속성 갑주, 오라, 무기 연출 활성화 |
| 3 | 승급 심화 | 상위 티어 변신 외형 | 같은 속성이라도 더 거대하고 복잡한 실루엣 |

## 상태 전환 규칙
- `인 장착`
  - 현재 캐릭터의 속성과 변신 계열이 결정된다.
- `비전투 기본 상태`
  - 마을, 이동, 대기, 상호작용 기본 상태
  - 현재 인 계열의 `1티어 외형`이 항상 유지된다.
- `변신`
  - 전투 진입 또는 플레이어 입력으로 발동
  - 현재 장착한 인의 `현재 티어 외형`을 활성화한다.
- `변신 해제`
  - 전투 종료 또는 수동 해제 시 복귀
  - 다시 `1티어 외형` 기본 상태로 돌아간다.

## 티어별 외형 차이 원칙

| 티어 | 비전투 외형 | 전투 외형 차이 | 읽혀야 하는 느낌 |
| :--- | :--- | :--- | :--- |
| `움결` | 단순한 1티어 기본폼 | 기본 오라, 간단한 갑주 조각 | 속성 입문 |
| `무늬` | 여전히 1티어 기본폼 | 패턴이 새겨진 갑주, 오라 분화 | 첫 변신 성장 |
| `물결` | 여전히 1티어 기본폼 | 유동적인 후광, 무기 궤적 강화 | 전투 위상 상승 |
| `울림` | 여전히 1티어 기본폼 | 실루엣 확대, 파편 공명 연출 | 상위 전투폼 |
| `숨결` | 여전히 1티어 기본폼 | 후광과 파편 흐름 증가 | 희귀 전투폼 |
| `빛살` | 여전히 1티어 기본폼 | 강한 발광, 큰 후광, 화려한 궤적 | 엔드게임 전반 |
| `여울` | 여전히 1티어 기본폼 | 거대한 실루엣과 공간 왜곡감 | 종결 직전 |
| `온결` | 여전히 1티어 기본폼 | 최종 갑주/후광/파편 붕괴 연출 | 궁극 변신 |

## 속성별 외형 해석

### 화
- 비전투: 얇은 붉은 균열, 미세한 열기 잔광
- 전투: 불꽃 갑주, 전진형 궤적, 폭발 파편

### 수
- 비전투: 푸른 막, 잔잔한 파동
- 전투: 수막 갑주, 냉기 궤적, 흐르는 잔광

### 지
- 비전투: 암갈색 결 흔적, 단단한 표면감
- 전투: 암석 갑주, 낙하 파편, 무거운 충돌감

### 풍
- 비전투: 가는 선형 잔광, 빠른 흔들림
- 전투: 날카로운 풍절 갑주, 분산 궤적, 선회 잔상

### 광
- 비전투: 밝은 반사광, 깨끗한 윤곽
- 전투: 백금색 광휘 갑주, 관통 광선, 후광 확장

### 암
- 비전투: 먹빛 잔향, 흐린 그림자 층
- 전투: 암영 갑주, 잠식 파동, 붕괴 파편

## 디자인 체크포인트
- 비전투 외형만 봐도 현재 속성은 알아볼 수 있어야 한다.
- 전투 외형은 한눈에 티어 차이가 느껴져야 한다.
- 방어구를 바꿔도 외형 위상이 흔들리면 안 된다.
- 같은 속성이라면 비전투 기본 외형은 유지되고, 전투 외형만 상위 티어로 교체되는 구조가 명확해야 한다.

## 티어별 읽기 규칙
- `인: 움결 화`
  - 비전투: `움결 화`의 1티어 기본 외형
  - 전투: `움결 화` 변신 외형
- `인: 물결 화`
  - 비전투: 여전히 해당 계열의 1티어 기본 외형 사용
  - 전투: `물결 화` 변신 외형
- `인: 온결 화`
  - 비전투: 해당 계열의 1티어 기본 외형 사용
  - 전투: `온결 화` 종결 변신 외형

## 시각 설계 원칙
- 비전투 외형은 단정하고 읽기 쉬워야 한다.
- 전투 외형은 속성 오라, 갑주 틈새 발광, 무기 궤적으로 위상을 표현한다.
- 티어가 오를수록 실루엣, 발광량, 파편 연출, 후광 크기가 커진다.
- 방어구는 스탯 장비일 뿐, 외형 위상 판단 기준이 아니다.

## 속성별 기본 인상
- 화: 붉은 균열, 열기 잔광
- 수: 푸른 수막, 냉기 흐름
- 지: 암갈색 파편, 무게감
- 풍: 선형 잔광, 날카로운 흐름
- 광: 백금색 광휘, 반사광
- 암: 먹빛 안개, 붕괴 잔향
