# 속성별 언령결 정책

## 목적
`움결`, `무늬` 티어의 언령결을 `속성별 3개` 구조로 확장하되, 언령결 자체는 복잡한 계산이 아닌 `속성 데미지와 연출용 액티브`로 정리한다.

## 핵심 정책
- `씨앗` 티어 언령결은 미도입
- `움결` 티어는 각 속성마다 `3개`
- `무늬` 티어는 각 속성마다 `3개`
- `움결`은 각 속성마다 `스토리 2개 + 제작 1개`
- `무늬`는 각 속성마다 `스토리 1개 + 제작 2개`
- `물결` 이후는 각 속성마다 `1개`를 기본으로 한다.

## 속성별 코어 역할

| 속성 | 기본 역할 | 핵심 키워드 | 화면 인상 |
| :--- | :--- | :--- | :--- |
| 불 | 속성 데미지 | 폭발, 화염, 직진 | 가장 직관적인 공격 연출 |
| 물 | 속성 데미지 | 파동, 냉기, 흐름 | 넓고 부드러운 타격감 |
| 땅 | 속성 데미지 | 충돌, 낙하, 압박 | 묵직한 한방 연출 |
| 바람 | 속성 데미지 | 절단, 선회, 분산 | 빠르고 날카로운 타격감 |
| 빛 | 속성 데미지 | 광선, 섬광, 관통감 | 밝고 강한 화면 장악 |
| 어둠 | 속성 데미지 | 암영, 잠식, 붕괴감 | 먹빛과 소거 연출 |

## 티어 내 3단 구조

### 움결 3단 구조
- `1번`: 기본형
  - 사용법이 가장 쉽다.
  - 스토리 지급
- `2번`: 응용형
  - 같은 속성의 다른 범위나 타격 감각을 보여준다.
  - 스토리 지급
- `3번`: 제작형
  - 같은 속성 안의 강한 연출 차이를 준다.
  - 제작 획득

### 무늬 3단 구조
- `1번`: 확장형
  - 움결의 대표 타격을 한 단계 키운다.
  - 스토리 지급
- `2번`: 분화형
  - 같은 속성 안에서 범위나 궤적 차이를 연다.
  - 제작 획득
- `3번`: 특화형
  - 같은 속성 내에서 가장 화려한 연출을 맡는다.
  - 제작 획득

## 속성별 상세 정책

### 불
- 정체성: `직진 화염 -> 폭발 -> 광역 화염`
- 움결:
  - 1번: 직선 화염 또는 짧은 투사체
  - 2번: 좁은 범위 폭발
  - 3번: 강한 관통감의 화염 제작 언령
- 무늬:
  - 1번: 화염 범위 확장형
  - 2번: 휘몰아치는 화염 분화형
  - 3번: 가장 강한 폭발 연출 특화형

### 물
- 정체성: `수류 -> 냉기 파동 -> 광역 한기`
- 움결:
  - 1번: 직선 수류 또는 짧은 파동
  - 2번: 퍼지는 냉기 파동형
  - 3번: 강한 얼음 타격감 제작 언령
- 무늬:
  - 1번: 냉기 범위 확장형
  - 2번: 넓게 휘감는 파도형
  - 3번: 얼음 붕괴 연출 특화형

### 땅
- 정체성: `바닥 충격 -> 돌기둥 -> 낙하 압착`
- 움결:
  - 1번: 짧은 지면 충격
  - 2번: 솟아오르는 돌기둥
  - 3번: 묵직한 낙하 제작 언령
- 무늬:
  - 1번: 돌기둥 확장형
  - 2번: 갈라지는 대지 분화형
  - 3번: 가장 무거운 압착 연출 특화형

### 바람
- 정체성: `절단 -> 선회 -> 다단 분산`
- 움결:
  - 1번: 전방 절단 또는 짧은 돌진
  - 2번: 적중 후 분산 타격형
  - 3번: 빠른 연속 절단 제작형
- 무늬:
  - 1번: 넓은 부채꼴 절단
  - 2번: 선회하며 흩어지는 바람형
  - 3번: 가장 빠른 다단 히트 특화형

### 빛
- 정체성: `광선 -> 섬광 -> 대형 관통`
- 움결:
  - 1번: 짧은 광선
  - 2번: 퍼지는 섬광형
  - 3번: 곧게 꿰뚫는 제작형
- 무늬:
  - 1번: 관통 광선 확장형
  - 2번: 넓게 퍼지는 장막형
  - 3번: 가장 강한 관통 연출 특화형

### 어둠
- 정체성: `암영 투사 -> 잠식 파동 -> 붕괴 소거`
- 움결:
  - 1번: 짧은 암영 투사체
  - 2번: 퍼지는 암영 파동형
  - 3번: 잠식감이 강한 제작형
- 무늬:
  - 1번: 암영 범위 확장형
  - 2번: 내려앉는 장막 분화형
  - 3번: 가장 강한 소거 연출 특화형

## 운영 원칙
- 각 속성 라인은 `기본형 -> 응용형 -> 제작형`으로 자연스럽게 이해돼야 한다.
- 같은 속성의 `움결 3개`를 경험한 뒤 `무늬 3개`에서 확장과 분화를 체감하게 해야 한다.
- 제작형은 스토리 지급형보다 메타 고정값이 아니라 `선택지`여야 한다.
- 속성별 3개 구성은 복잡한 상태효과 차별화가 아니라 `같은 속성 안의 다른 타격감과 연출`을 보여줘야 한다.
- 실제 데미지 계산의 깊이는 언령이 아니라 `진언`이 담당한다.

## 후속 작업
- 속성별 `움결 3개`, `무늬 3개`의 실제 이름 초안 작성
- 각 언령결의 시전 감각, 범위 형태, 연출 강도 정의
- 스토리 지급 순서와 제작 해금 보스 연결
