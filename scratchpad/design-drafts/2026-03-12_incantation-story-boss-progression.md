# 움결/무늬 언령결 스토리 지급 및 보스 해금 연결표

## 목적
초기 언령결의 `스토리 지급`과 `제작 해금`이 실제 플레이 흐름에서 어떻게 이어지는지 고정한다.

## 공통 원칙
- `움결`은 각 속성 라인마다 `스토리 2개 + 제작 1개`
- `무늬`는 각 속성 라인마다 `스토리 1개 + 제작 2개`
- 제작 언령결은 해당 속성 보스의 파편/촉매 파밍과 자연스럽게 연결돼야 한다.

## 움결

| 속성 | 1차 스토리 지급 | 2차 스토리 지급 | 제작 해금 | 연결 보스 |
| :--- | :--- | :--- | :--- | :--- |
| 불 | `앞을 밝혀라` | `불길아 번져라` | `타올라 꿰뚫어라` | `몽당연필 기사단장` |
| 물 | `맑게 흘러라` | `서늘히 감싸라` | `차갑게 얼려라` | `서릿발 서고 수호자` 선행 파편 노출 |
| 땅 | `굳게 버텨라` | `바위여 막아서라` | `대지를 눌러라` | `몽당연필 기사단장` 보조 파편, 이후 `붕괴한 성벽 거신` 예고 |
| 바람 | `바람아 스쳐라` | `빠르게 갈라라` | `흩날려 베어라` | `유리폭풍 추적자` 선행 파편 노출 |
| 빛 | `찬란히 비추어라` | `빛으로 감싸라` | `곧게 꿰뚫어라` | `여명 집행관` 선행 파편 노출 |
| 어둠 | `어둠아 내려라` | `그림자여 감춰라` | `조용히 잠식하라` | `망각의 잉크 드래곤` |

## 무늬

| 속성 | 스토리 지급 | 제작 해금 1 | 제작 해금 2 | 연결 보스 |
| :--- | :--- | :--- | :--- | :--- |
| 불 | `불꽃이여 모여라` | `붉은 불길 휘몰아라` | `타는 심장 터져라` | `몽당연필 기사단장` -> `여명 집행관` |
| 물 | `서리숨결 퍼져라` | `차가운 파도 휘감아라` | `얼음결이 묶어라` | `서릿발 서고 수호자` |
| 땅 | `대지를 굳게 세워라` | `돌기둥이 솟아라` | `무거운 결로 눌러라` | `붕괴한 성벽 거신` |
| 바람 | `날선 바람 휘감아라` | `폭풍의 날개 흩뿌려라` | `바람자국 쫓아가라` | `유리폭풍 추적자` |
| 빛 | `빛조각이 쏟아져라` | `눈부신 장막 펼쳐라` | `광휘의 창 꿰뚫어라` | `여명 집행관` |
| 어둠 | `어둠손길 얽매어라` | `검은 장막 내려앉아라` | `침묵의 그림자 삼켜라` | `망각의 잉크 드래곤` -> `침묵의 심연 군주` |

## 챕터 배치 원칙
- 각 속성의 첫 `움결` 언령은 해당 속성의 존재를 알려주는 튜토리얼 보상으로 둔다.
- 두 번째 `움결` 언령은 같은 속성의 다른 범위/타격 감각을 보여주는 중반 스토리 보상으로 둔다.
- 세 번째 `움결` 언령은 처음으로 직접 제작하게 만드는 학습 목표로 둔다.
- `무늬`는 티어 진입 직후 대표 1개를 스토리로 주고, 나머지는 보스 파밍과 제작으로 넘긴다.

## 운영 메모
- 초반 모든 속성을 한 번에 열더라도, 실제 파밍 보스 연결은 각 속성별로 분리해 제작 목표가 뚜렷해야 한다.
- 보스 연결은 `해당 속성 메인 보스 1명 + 후반 보조 보스 1명` 구조를 기본으로 한다.
