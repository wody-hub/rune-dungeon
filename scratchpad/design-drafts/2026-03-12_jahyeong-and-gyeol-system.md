# 자형 -> 결 이원화 시스템 설계

## 목적
현재 `결`이 너무 많은 의미를 떠안고 있는 문제를 해소하고, 초반/가벼운 플레이에서 부담 없이 사용할 수 있는 `100% 확정 제조 층`과 상위 `확률 각인 층`을 분리한다.

## 문제 정의
- 지금 구조에서는 글자를 만드는 것 자체가 이미 `결`로 취급된다.
- 그런데 `결`은 의미가 부여된 강한 아이템 느낌이 강해서, 초반에 가볍게 찍어 쓰는 글자와 후반 핵심 아이템이 같은 이름 아래 섞인다.
- 이 상태로 가면 `초반 실험성`과 `후반 희소성`을 동시에 잡기 어렵다.

## 핵심 결론
- `자모 파편 -> 자형 -> 결` 3단계로 분리한다.
- `자형`은 `100% 확정 합성`으로 만든다.
- `결`은 `자형`에 각인을 거쳐 완성되는 의미 부여 아이템이다.
- 초반 유저는 `자형`만으로도 충분히 전투와 실험이 가능하고, 중후반에는 `결`을 목표로 파밍/각인한다.

## 추천 용어

### 최종 추천
- `자형`

의미:
- 아직 의미가 봉인된 `글자의 형태`
- 전투에 쓸 수는 있지만 완성된 힘은 아닌 상태
- `결`보다 가볍고, `글자 룬`보다 게임 내 고유명사로 쓰기 좋음

### 사용 예시
- `자형: 강`
- `자형: 불`
- `자형: 빛`
- `결: 강`
- `결: 태양`
- `결: 어둠을 밝히는 불꽃이여`

### 대안 검토
- `글자`:
  - 장점: 직관적
  - 단점: 시스템 명칭으로는 너무 평범함
- `문자`:
  - 장점: 의미는 분명함
  - 단점: 세계관 톤이 약함
- `자형`:
  - 장점: 가공 전 단계라는 느낌이 강하고 `결`과도 잘 구분됨
  - 단점: 첫 학습이 약간 필요함

추천:
- 시스템 명칭은 `자형`
- 설명 문구에서는 `글자의 형태인 자형`처럼 병기

## 새 제작 흐름

### 1단계. 자모 파편
- 슬롯을 차지하지 않는 수량형 재화
- 몬스터, 자동/방치, 던전에서 획득

### 2단계. 자형 합성
- 자모 파편을 사용해 유효한 한글을 만들면 `자형`이 된다.
- 이 단계는 `100% 확정`
- 초반 유저가 부담 없이 조합을 실험하는 층

예시:
- `ㄱ + ㅏ + ㅇ -> 자형: 강`
- `ㅂ + ㅜ + ㄹ -> 자형: 불`

### 3단계. 결 각인
- `자형` 중 의미가 허용된 글자/단어/문장을 `각인`하면 `결`이 된다.
- 이 단계부터 `확률`, `돌`, `먹`, 희귀도`가 붙는다.

예시:
- `자형: 강 + 각인 -> 결: 강`
- `자형: 태 + 자형: 양 + 돌: 새김 -> 결: 태양`
- `자형` 여러 개 + `돌: 말문` -> `결: 문장`

## 아이템 위계 정리

| 단계 | 명칭 | 제작 방식 | 확률 | 역할 |
| :--- | :--- | :--- | :--- | :--- |
| 1차 | `자모 파편` | 드랍 | 없음 | 재화 |
| 2차 | `자형` | 합성 | `100%` | 초반 장착, 실험, 결 재료 |
| 3차 | `결: 글자` | 각인 | 있음 | 의미가 부여된 단일 글자 아이템 |
| 4차 | `결: 단어` | 각인 | 있음 | 진언결 |
| 5차 | `결: 문장` | 각인 | 있음 | 언령결 |

## 초반 플레이 설계 의도
- 초반은 `자형`만으로도 충분히 전투 세팅이 되게 한다.
- `결`은 초반에도 만들 수 있지만, `목표 아이템`에 가깝게 둔다.
- 이렇게 하면 `실험은 싸고 빠르게`, `완성은 느리고 묵직하게` 분리된다.

## 자형의 사용처

### 1. 직접 장착
- 진언결과 같은 계열 슬롯에 직접 꽂을 수 있다.
- 낮은 수치지만 즉시 체감 가능한 능력치를 준다.
- 언령결 슬롯에는 장착할 수 없다.

### 2. 상위 결 재료
- `결: 글자`, `결: 단어`, `결: 문장`의 재료가 된다.

### 3. 분해/회수
- 필요 없는 `자형`은 파편 일부 환급 또는 품질 경험치 재료로 사용 가능하다.

## 결의 역할

### `결: 글자`
- `자형` 중 의미가 살아 있는 글자를 각인해 만든 단일 글자 결
- `자형`보다 높은 수치, 고유 효과, 시각 연출 보유

### `결: 단어`
- 진언결
- 패시브, 세트, 빌드 핵심

### `결: 문장`
- 언령결
- 액티브 스킬, 주문, 궁극기

## 자모 능력치 구조 재설계

## 기본 원칙
- 모든 자모는 하나의 능력 기여를 가진다.
- `초성`은 전투 성향
- `중성`은 속성/에너지 성향
- `종성`은 적용 방식 또는 보조 효과
- 최종 `자형` 능력치는 세 축을 합성해 계산한다.

### 1. 초성: 전투 성향

| 초성군 | 의미 | 기본 능력 방향 |
| :--- | :--- | :--- |
| `ㄱ, ㅋ` | 날카로움 | 치명타 확률, 관통 |
| `ㄴ, ㄹ` | 흐름 | 공격 속도, 이동 속도 |
| `ㄷ, ㅌ` | 충격 | 기본 공격력, 강타 |
| `ㅁ, ㅂ, ㅍ` | 버팀/파괴 | 최대 체력, 방어, 파쇄 |
| `ㅅ, ㅈ, ㅊ` | 정밀 | 명중, 스킬 위력, 상태 이상 적중 |
| `ㅇ, ㅎ` | 순환/정신 | 마나, 재생, 쿨다운 완화 |

### 2. 중성: 속성/에너지 성향

| 중성군 | 의미 | 기본 능력 방향 |
| :--- | :--- | :--- |
| `ㅏ, ㅑ` | 화염 | 화염 피해, 점화 |
| `ㅓ, ㅕ` | 대지 | 방어, 압박, 경직 |
| `ㅗ, ㅛ` | 빛 | 보호막, 시야, 관통 광휘 |
| `ㅜ, ㅠ` | 물 | 냉기, 둔화, 회복 |
| `ㅡ, ㅣ` | 바람 | 이동, 연속 타격, 회피 |
| `ㅐ, ㅔ, ㅚ, ㅟ, ㅢ` | 왜곡 | 희귀/특수 속성, 상위 결 재료 적성 |

### 3. 종성: 적용 방식

| 종성군 | 의미 | 기본 능력 방향 |
| :--- | :--- | :--- |
| 없음 | 개방 | 기본 수치 증폭 |
| `ㄱ, ㄴ, ㄷ` | 고정 | 방어, 안정성, 지속 |
| `ㄹ, ㅁ` | 흡수 | 흡혈, 자원 회복, 유지력 |
| `ㅂ, ㅅ, ㅈ` | 폭발 | 추가 타격, 범위, 발동 확률 |
| `ㅇ, ㅎ` | 확산 | 광역화, 관통, 전염 |
| 겹받침 | 변이 | 희귀 효과, 상위 결 적성 증가 |

## 자형 계산 방식

예시 1. `자형: 강`
- `ㄱ` = 날카로움
- `ㅏ` = 화염
- `ㅇ` = 확산
- 결과:
  - 치명/관통 성향
  - 화염 추가 피해
  - 범위 또는 확산 보정

예시 2. `자형: 불`
- `ㅂ` = 버팀/파괴
- `ㅜ` = 물
- `ㄹ` = 흡수
- 결과:
  - 생존 또는 파쇄
  - 냉기/물 성향
  - 흡수/유지력 보정

주의:
- `자형`의 글자 의미와 자모 능력은 반드시 완전히 일치할 필요는 없다.
- `의미`는 `결` 각인 단계에서 강화되고, `자형`은 어디까지나 `자모 조합 결과의 수치체`로 본다.

## 추천 밸런스 원칙

### 자형
- 100% 합성
- 낮은 비용
- 낮은 성능
- 높은 실험성

### 결
- 확률 각인
- `돌`, `먹` 사용
- 높은 성능
- 낮은 실험성, 높은 목표성

## 추천 UI 표현
- 탭 명:
  - `자형 제조`
  - `각인`
- 버튼 명:
  - `자형 합성`
  - `결 각인`
- 설명 문구:
  - `자모 파편을 조합해 자형을 제조합니다. 자형 제조는 100% 성공합니다.`
  - `자형에 의미를 새겨 결로 각인합니다. 결 각인은 확률과 촉매가 필요합니다.`

## 문서 반영 기준
- `결`은 앞으로 `의미가 각인된 완성 아이템`에만 사용한다.
- 현재 `글자결`로 적힌 일부 표현은 `자형` 또는 `결: 글자`로 분리해 정리해야 한다.
- 초반 장착용 기초 아이템은 `자형`, 최종 목표 아이템은 `결`로 구분한다.
