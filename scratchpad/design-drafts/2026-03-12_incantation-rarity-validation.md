# 언령결 희귀도 비율 1차 교차 검증

## 목적
언령결 실제 자모 구성이 티어별 파편 희귀도 목표와 맞는지 검증하고, 보정이 필요한 문장을 식별한다.

## 기준 문서
- `2026-03-12_fragment-rarity-table.md`
- `2026-03-12_incantation-composition-table.md`
- `2026-03-12_incantation-jamo-breakdown.md`

## 검증 방식
- 각 티어의 언령결 6개를 기준으로 자모 희귀도 경향을 본다.
- 아직 정확한 자동 계산이 아닌 1차 정성 검수다.
- 언령결은 문장 길이 보정이 크게 작용하므로 `자모 희귀도`와 `문장 길이`를 함께 본다.
- 판정 기준:
  - `적정`: 현재 티어 감각과 대체로 일치
  - `쉬움`: 목표보다 희귀/특수 자모 비중이 낮음
  - `어려움`: 목표보다 희귀/특수 자모 비중이 높음

## 티어별 목표 상기

| 티어 | 목표 방향 |
| :--- | :--- |
| `움결` | 기본 + 중급 중심 |
| `무늬` | 기본/중급 중심 + 희귀 소량 |
| `물결` | 중급 비중 상승 + 희귀 진입 |
| `울림` | 희귀 파편이 본격 핵심 |
| `숨결` | 희귀 핵심 + 특수 소량 |
| `빛살` | 희귀 중심 + 특수 진입 |
| `여울` | 희귀 중심 + 특수 확대 |
| `온결` | 희귀/특수 중심 |

## 티어별 판정

### 움결
- 전반적으로 길이 보정이 난이도를 만들고 있다.
- `앞을 밝혀라`, `맑게 흘러라`, `찬란히 비추어라`는 희귀 자모가 자연스럽게 섞여 있다.
- `그림자처럼 스며라`는 길이는 충분하지만 자모 희귀도는 상대적으로 완만하다.
- `바람처럼 흘러라`도 비슷하게 길이 대비 희귀도는 낮은 편이다.

판정:
- 전체: `적정`
- 보정 후보: `바람처럼 흘러라`, `그림자처럼 스며라`

### 무늬
- `불꽃이여 모여라`, `빛조각이 쏟아져라`, `날선 바람 휘감아라`는 티어감이 좋다.
- `대지를 굳게 세워라`도 `ㅐ`, `ㅔ`, `ㅝ`가 섞여 난이도가 살아 있다.
- `서리숨결 퍼져라`, `어둠손길 얽매어라`는 적정 범위지만 상대적으로 덜 날카롭다.

판정:
- 전체: `적정`
- 보정 후보: `서리숨결 퍼져라`

### 물결
- `어둠을 밝히는 불꽃이여`와 `빛의 장막이여 펼쳐져라`는 특수/희귀 자모가 충분하다.
- `고요한 물결이여 덮쳐라`, `검은 장막이여 내려앉아라`도 적정 수준이다.
- `깊은 대지여 솟아올라라`, `날선 바람이여 흩날려라`는 문장 길이에 비해 희귀 자모 밀도가 다소 낮다.

판정:
- 전체: `약간 쉬움`
- 보정 후보: `깊은 대지여 솟아올라라`, `날선 바람이여 흩날려라`

### 울림
- `서릿발이여 대지를 묶어라`, `폭풍날개여 전장을 휩쓸어라`, `빛의 파동이여 아군을 감싸라`는 티어 위상과 잘 맞는다.
- `타오른 숨결이여 삼켜라`는 무난하지만 상단까지는 아니다.
- `견고한 벽이여 길을 갈라라`, `깊은 그림자여 숨을 눌러라`는 길이 대비 희귀/특수 비중이 낮다.

판정:
- 전체: `적정`
- 보정 후보: `견고한 벽이여 길을 갈라라`, `깊은 그림자여 숨을 눌러라`

### 숨결
- `타오르는 태양이여 어둠을 삼켜라`, `성스러운 광휘여 길을 열고 비추라`, `끝없는 밤이여 시선과 숨을 삼켜라`는 상위 티어 감각이 충분하다.
- `깊은 심해여 적의 숨을 멎게 하라`는 적정선이다.
- `고요한 산맥이여 적진을 짓눌러라`, `하늘의 바람결이여 만물을 가르라`는 문장 위상은 좋지만 특수 파편 비중이 낮다.

판정:
- 전체: `약간 쉬움`
- 보정 후보: `고요한 산맥이여 적진을 짓눌러라`, `하늘의 바람결이여 만물을 가르라`

### 빛살
- `만개의 불꽃이여 적진을 덮어라`는 티어감이 좋다.
- `무너지는 산벽이여 길을 끊어라`, `별빛의 칼날이여 밤을 수놓아라`, `삼켜진 어둠이여 존재를 흐리게 하라`도 적정 범위다.
- `혹한의 물결이여 전장을 얼려라`, `하늘의 칼바람이여 무리를 가르라`는 상위 티어 치고는 특수 비중이 약한 편이다.

판정:
- 전체: `적정`
- 보정 후보: `혹한의 물결이여 전장을 얼려라`, `하늘의 칼바람이여 무리를 가르라`

### 여울
- `창조의 불길이여 세계의 결을 뒤집어라`, `끝없는 폭풍이여 모든 경계를 지워라`, `여명의 칼날이여 어둠의 결을 꿰뚫어라`는 상위 티어 감각이 강하다.
- `영원의 조류여 만물의 숨을 잠재워라`, `태고의 대지여 모든 길과 틈을 닫아라`, `영원의 그림자여 모든 빛의 숨을 삼켜라`는 적정 범위다.
- 전체적으로 티어 위상은 안정적이다.

판정:
- 전체: `적정`
- 보정 후보: `영원의 조류여 만물의 숨을 잠재워라`

### 온결
- `하늘과 땅과 사람이 하나 되어 빛나리`는 길이는 짧지만 특수/희귀 자모 구성이 강해 최종 티어 감각이 있다.
- `태초의 불길이여 만 갈래를 하나로 돌려라`, `태초의 터전이여 흔들린 결을 온전케 하라`, `태초의 밤이여 모든 그림자를 하나로 거두어라`는 적정 수준이다.
- `태초의 바다여 흩어진 숨결을 하나로 품어라`, `태초의 숨이여 모든 경계를 하나로 흐르게 하라`는 문장 위상 대비 특수 파편 비중이 낮다.

판정:
- 전체: `약간 쉬움`
- 보정 후보: `태초의 바다여 흩어진 숨결을 하나로 품어라`, `태초의 숨이여 모든 경계를 하나로 흐르게 하라`

## 1차 결론
- 초중반 티어인 `움결`, `무늬`는 큰 문제 없이 통과 가능하다.
- `물결` 이후부터는 길이로 난이도를 보정하는 문장과 자모 희귀도로 난이도를 보정하는 문장이 섞여 있다.
- 특히 `숨결`, `온결`의 일부 문장은 세계관 위상은 충분하지만 파편 희귀도 기준으로는 약할 수 있다.
- `여울`은 전체적으로 가장 안정적이고, `빛살`은 일부 속성만 미세 보정이 필요하다.

## 수정 방향 제안
- 쉬운 항목은 문장 일부를 희귀/특수 자모가 들어가는 표현으로 교체한다.
- 문장성이 좋은 항목은 유지하고, 대신 `돌: 깃듦` 추가 요구나 특정 특수 파편 요구 조건을 붙여 티어 난이도를 보정한다.
- `온결`처럼 세계관적 상징성이 강한 문장은 이름 교체보다 제작 조건 강화가 더 적합하다.
