# 티어별 진언결 이름표

## 목적
각 티어별 대표 진언결 이름을 먼저 확정해, 이후 파편 요구량과 제작 난이도를 실제 데이터로 검증할 수 있게 한다.

## 기본 원칙
- 티어당 진언결은 `5개`
- 역할은 되도록 다음 5종으로 고정
  - 공격형
  - 속도형
  - 생존형
  - 속성형
  - 특수형
- 실제 옵션은 다음 축을 중심으로 단순화한다.
  - `데미지 % 증가`
  - `공격 속도 증가`
  - `이동 속도 증가`
  - `속성 공격력 % 증가`
  - `치명타 확률 증가`
  - `치명타 피해 증가`
  - `스킬 쿨타임 감소`
  - `스턴 확률 증가`
  - `받는 스턴 시간 감소`
  - `받는 스턴 확률 감소`
- `명중률`, `회피율`, `관통력`은 제외한다.
- 스턴 계열은 PvP 대응용 옵션으로 두고, PvE에서는 보스전 위주로만 의미를 가진다.

## 역할 고정 정의
- `공격형`
  - 담당 옵션: `데미지 % 증가`, `치명타 확률 증가`, `치명타 피해 증가`
  - 역할: 가장 직관적인 화력 상승 축
- `속도형`
  - 담당 옵션: `공격 속도 증가`, `이동 속도 증가`, `스킬 쿨타임 감소`
  - 역할: 전투 템포와 조작감을 높이는 축
- `생존형`
  - 담당 옵션: `받는 스턴 시간 감소`, `받는 스턴 확률 감소`
  - 역할: 특히 PvP와 보스전에서 안정성을 높이는 축
- `속성형`
  - 담당 옵션: `속성 공격력 % 증가`
  - 역할: 특정 속성 빌드를 강하게 밀어주는 축
- `특수형`
  - 담당 옵션: `스턴 확률 증가`
  - 역할: PvP 중심의 제압 옵션 축

## 설계 의도
- 씨앗~움결은 직관적인 단어 위주
- 무늬~물결은 전투 기능이 명확한 이름 위주
- 울림 이후는 상위 결다운 상징성과 존재감을 강화
- 온결은 세계관 최상위에 어울리는 짧고 강한 이름 위주
- 각 티어의 진언은 `5개만 기억하면 전체 빌드 구조를 이해할 수 있게` 단순화한다.
