# 초기 언령결 공급 정책

## 목적
초반 언령결은 제작 난도가 상대적으로 높기 때문에, 스토리 지급과 제작 경험을 분리해 진입 장벽을 낮추면서도 제작 학습 루프를 유지한다.

## 고정 정책
- 레벨 정책은 다음과 같이 고정한다.
  - `씨앗`: Lv 1~9
  - `움결`: Lv 10~39
  - `무늬`: Lv 40~69
  - `물결`: Lv 70~99
  - `울림`: Lv 100~129
  - `숨결`: Lv 130~159
  - `빛살`: Lv 160~189
  - `여울`: Lv 190~199
  - `온결`: Lv 200
- `씨앗` 티어 언령결은 미도입
- `움결`, `무늬`는 초반 학습용 확장 티어로서 각 속성 라인마다 언령결 `3개`씩 기획
- `물결` 이후는 티어당 속성별 `1개`를 기본 원칙으로 전환

## 티어별 공급 구조

### 움결
- 각 속성 라인마다 총 `3개`
- 각 속성 라인마다 `스토리 지급 2개`
- 각 속성 라인마다 `제작 획득 1개`
- 목표:
  - 첫 언령 사용 경험 보장
  - 두 번째 언령으로 언령 슬롯 운용 감각 강화
  - 세 번째 언령은 제작으로 직접 완성하게 만들어 `자형 -> 문장 배열 -> 돌: 말문 각인` 루프 학습

### 무늬
- 각 속성 라인마다 총 `3개`
- 각 속성 라인마다 `스토리 지급 1개`
- 각 속성 라인마다 `제작 획득 2개`
- 목표:
  - 스토리로 상위 티어 진입 감각 제공
  - 본격적인 언령 제작 반복 경험 시작
  - 제작 비중을 높여 중반부 파밍과 재료 관리 루프로 연결

## 설계 의도
- `움결`은 모든 속성 라인에서 체험 비중이 더 높다.
- `무늬`는 모든 속성 라인에서 제작 비중이 더 높다.
- 이렇게 하면 초반에는 언령의 재미를 빠르게 보여주고, 중반 진입 직전부터는 제작의 비중을 자연스럽게 늘릴 수 있다.

## 콘텐츠 배치 원칙
- 스토리 지급 언령결은 범용성과 연출 가독성이 높은 것을 우선 배치한다.
- 제작 언령결은 속성 특화나 운용 차별점이 더 뚜렷한 것을 우선 배치한다.
- 초반 지급 언령결은 너무 강한 메타 고정값이 아니라, 이후 제작 언령결로 갈아탈 동기를 남겨야 한다.

## 권장 운영 흐름
1. 각 속성 라인에서 `움결` 초반 스토리로 첫 언령결 지급
2. 각 속성 라인에서 `움결` 후반 스토리로 두 번째 언령결 지급
3. 같은 구간에서 세 번째 `움결` 언령결 제작 유도
4. 각 속성 라인에서 `무늬` 진입 스토리로 첫 `무늬` 언령결 지급
5. `무늬` 구간 동안 같은 속성의 나머지 두 언령결을 제작 목표로 제공

## 후속 작업
- `움결` 속성별 3개, `무늬` 속성별 3개의 실제 언령결 목록 확정
- 각 언령결의 `스토리 지급` / `제작 전용` 태그 지정
- 스토리 챕터별 지급 시점과 보스 드랍 재료 연결
