# 자동/수동 드랍 테이블 초안

## 목적
자동/방치와 수동 던전의 보상을 실제 콘텐츠 운영이 가능한 수준으로 구분해, 각 모드의 역할과 파밍 기대값을 명확히 한다.

## 핵심 결론
- 자동/방치는 `기본 재화 + 공용 기본 파편 + 일부 중급 파편`의 장기 누적 공급처다.
- 수동 던전은 `중급/희귀/특수 파편 + 돌 + 먹 + 완성 결 직드랍`의 핵심 공급처다.
- 같은 재료 축을 공유하되, 자동은 `누적`, 수동은 `가속` 역할로 분리한다.
- 상위 티어로 갈수록 `완성 결 직드랍`보다 `돌`, `조각`, `먹`의 가치가 커진다.

## 콘텐츠 분류

### 자동/방치
- 필드 자동 사냥
- 오프라인 누적 보상

### 수동 던전
- 일반 던전
- 엘리트 던전
- 보스 던전
- 특수 던전
- 근원의 나라

## 자동/방치 드랍 테이블

| 콘텐츠 | 핵심 보상 | 보조 보상 | 금지 또는 제한 보상 |
| :--- | :--- | :--- | :--- |
| 필드 자동 사냥 | 골드, 경험치, 공용 기본 파편 | 중급 파편 저확률, 하위 글자결 저확률, `돌: 새김` 극저확률 | `돌: 깃듦`, 특수 파편, 핵심 `지킴결` |
| 오프라인 누적 보상 | 골드, 경험치, 공용 기본 파편 묶음 | 중급 파편 소량, 하위 `남은결` 극저확률 | `돌: 말문`, `돌: 깃듦`, 희귀/특수 파편 대량 공급 |

## 수동 던전 드랍 테이블

| 콘텐츠 | 핵심 보상 | 보조 보상 | 특징 |
| :--- | :--- | :--- | :--- |
| 일반 던전 | 공용 기본 파편, 중급 파편, 골드, 경험치 | 하위 글자결, `돌: 새김`, 약한 `남은결` | 초중반 반복 파밍용 |
| 엘리트 던전 | 중급 파편, 희귀 파편, `돌: 새김` | `돌: 말문 조각`, 하위 진언결 직드랍, `돋움결` 저확률 | 중반 제작 가속 구간 |
| 보스 던전 | 희귀 파편, 특정 속성 파편, `돌: 말문`, `돌: 말문 조각` | 완성 글자결 직드랍, `남은결`, `돋움결`, 희귀 진언결 저확률 | 언령 진입 핵심 |
| 특수 던전 | 희귀 파편, 특수 파편, `돌: 깃듦 조각` | `돌: 깃듦`, `지킴결`, 상위 글자결/진언결 저확률 | 후반/엔드게임 파밍 핵심 |
| 근원의 나라 | `천지인` 파편, 하위 언령 강화 재료 | 상위 `먹`, 특수 파편, 낮은 확률 `돌: 깃듦` | 언령 각성 전용 루프 |

## 티어 구간별 자동/수동 보상 초안

| 티어 구간 | 자동/방치 핵심 | 수동 핵심 | 설계 의도 |
| :--- | :--- | :--- | :--- |
| `씨앗 ~ 움결` | 공용 기본 파편, 골드, 경험치 | `돌: 새김`, 중급 파편, 하위 글자결 | 초반 학습과 첫 각인 경험 제공 |
| `무늬 ~ 물결` | 기본 파편 + 중급 파편 소량 | 희귀 파편 진입, `돌: 말문 조각`, `남은결` | 수동 던전 가치가 본격적으로 드러나는 구간 |
| `울림 ~ 숨결` | 중급 파편 보조 수급 | 희귀 파편 중심, `돌: 말문`, 선택적 `돌: 깃듦`, `돋움결` | 언령/상위 진언 파밍의 핵심 구간 |
| `빛살 ~ 온결` | 중급 파편 일부 + 극저확률 희귀 파편 | 특수 파편, `돌: 깃듦 조각`, `지킴결`, 상위 완성 결 저확률 | 엔드게임 장기 파밍 구간 |

## 파편 드랍 방향

| 파편 등급 | 자동/방치 | 일반 던전 | 엘리트/보스 | 특수 던전 |
| :--- | :--- | :--- | :--- | :--- |
| 공용 기본 파편 | 높음 | 높음 | 보통 | 낮음 |
| 중급 파편 | 낮음 | 보통 | 높음 | 보통 |
| 희귀 파편 | 매우 낮음 | 낮음 | 높음 | 높음 |
| 특수 파편 | 사실상 없음 | 없음 | 낮음 | 높음 |
| 천지인 파편 | 없음 | 없음 | 없음 | 근원의 나라 전용 |

## 돌 드랍 방향

| 재료 | 자동/방치 | 일반 던전 | 엘리트 던전 | 보스 던전 | 특수 던전 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `돌: 새김` | 극저확률 | 보통 | 보통~높음 | 높음 | 낮음 |
| `돌: 말문 조각` | 없음 | 없음 | 낮음 | 보통~높음 | 보통 |
| `돌: 말문` | 없음 또는 극저확률 | 없음 | 매우 낮음 | 보통 | 보통~높음 |
| `돌: 깃듦 조각` | 없음 | 없음 | 없음 | 낮음 | 보통~높음 |
| `돌: 깃듦` | 없음 | 없음 | 없음 | 매우 낮음 | 낮음 |

## 먹 드랍 방향

| 재료 | 자동/방치 | 일반 던전 | 엘리트 던전 | 보스 던전 | 특수 던전 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `먹: 남김` | 극저확률 | 낮음 | 보통 | 보통 | 보통 |
| `먹: 돋움` | 극저확률 하위형 | 없음 또는 매우 낮음 | 낮음 | 보통 | 보통~높음 |
| `먹: 지킴` | 없음 | 없음 | 없음 | 매우 낮음 | 보통 |

## 완성 결 직드랍 방향

| 드랍 대상 | 일반 던전 | 엘리트 던전 | 보스 던전 | 특수 던전 |
| :--- | :--- | :--- | :--- | :--- |
| 글자결 | 낮음 | 보통 | 보통 | 낮음 |
| 진언결 | 없음 | 매우 낮음 | 낮음 | 낮음~보통 |
| 언령결 | 없음 | 없음 | 매우 낮음 | 매우 낮음 |

## 콘텐츠별 1회 보상 감각 예시

### 필드 자동 사냥 30분
- 골드 다량
- 경험치 다량
- 공용 기본 파편 다수
- 중급 파편 소량
- 낮은 확률로 하위 글자결 1개

### 일반 던전 1회
- 골드
- 경험치
- 공용 기본 파편 다수
- 중급 파편 소량~보통
- 낮은 확률 `돌: 새김`

### 엘리트 던전 1회
- 골드
- 경험치
- 중급 파편 보통
- 희귀 파편 소량
- `돌: 새김` 1개 기대 가능 구간
- 낮은 확률 `돌: 말문 조각`

### 보스 던전 1회
- 골드
- 경험치
- 희귀 파편 보통
- 특정 속성 파편 보통
- `돌: 말문 조각 1~2개` 기대 구간
- 낮은 확률 `돌: 말문`
- 낮은 확률 `먹: 남김`, `먹: 돋움`

### 특수 던전 1회
- 희귀 파편 보통
- 특수 파편 소량~보통
- `돌: 깃듦 조각 1개 전후` 기대 구간
- 낮은 확률 `돌: 깃듦`
- `먹: 지킴`, 상위 `먹: 돋움` 드랍 가능

## 초안 수치 감각

### `돌: 말문`
- 보스 4~8회 누적 시 1개 제작 가능
- 완제품 드랍으로 평균 체감은 더 짧아질 수 있음

### `돌: 깃듦`
- 특수 던전 12~15회 누적 시 1개 제작 가능
- 완제품은 드문 가속 장치로만 사용

### `먹`
- `남김`은 중반부터 체감되도록 보스/엘리트에 분산
- `돋움`은 보스/특수 던전 중심
- `지킴`은 특수 던전과 고티어 보스의 상징 보상

## 운영 원칙
- 자동/방치만으로도 하위 제작과 성장 유지가 가능해야 한다.
- 수동 던전은 상위 제작 재료 접근을 크게 앞당겨야 한다.
- 상위 보상이 모두 확률에만 묶이지 않도록 `조각 누적 보장`을 함께 둔다.
- `완성 결 직드랍`은 흥분 요소로만 쓰고, 핵심 성장 축은 여전히 제작에 둔다.

## 미결정 사항
- 던전 1회 기준 정확한 파편 개수
- 보스별 속성 파편 풀
- `돌: 새김`의 실제 체감 드랍 빈도
- `먹` 세부 등급과 상위/하위 버전 구분
