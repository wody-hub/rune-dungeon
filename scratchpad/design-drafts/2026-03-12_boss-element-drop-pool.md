# 보스별 속성 파편 풀 설계

## 목적
보스 던전이 단순 재료 창고가 아니라 `원하는 속성 빌드를 목표 파밍하는 콘텐츠`가 되도록, 보스별 속성 파편 풀과 보조 보상 방향을 정의한다.

## 핵심 결론
- 각 보스는 `메인 속성 1개`를 가진다.
- 보조 속성은 `인접 속성 1~2개`만 허용해 파밍 방향성을 흐리지 않는다.
- 보스 고유 재료는 `특정 속성 언령/진언 제작 가속`에 연결된다.
- 상위 티어로 갈수록 `속성 파편 + 돌 + 먹 + 고유 드랍`의 조합으로 파밍 정체성이 강해진다.

## 설계 원칙
- 플레이어는 특정 속성 빌드를 정하면 어떤 보스를 돌아야 하는지 바로 이해할 수 있어야 한다.
- 메인 속성 파편은 `보통~높음`, 보조 속성 파편은 `낮음~보통`, 비관련 속성은 원칙적으로 드랍하지 않는다.
- 동일 속성 보스가 티어별로 존재하더라도 상위 보스는 `더 높은 희귀도 파편`, `돌`, `먹` 비중으로 차별화한다.
- 보스 기믹과 드랍 속성은 서사와 전투 경험 모두에서 일치해야 한다.

## 기본 속성 축

| 속성 | 전투 이미지 | 대표 파편 경향 |
| :--- | :--- | :--- |
| 불 | 폭발, 직선, 연소 | `ㅏ`, `ㅑ`, `ㅌ`, `ㅍ` 계열 |
| 물 | 흐름, 둔화, 빙결 | `ㅜ`, `ㅠ`, `ㅐ`, `ㅁ` 계열 |
| 땅 | 장벽, 압박, 고정 | `ㄷ`, `ㅓ`, `ㄱ`, `ㅌ` 계열 |
| 바람 | 절단, 이동, 분산 | `ㄹ`, `ㅡ`, `ㅣ`, `ㅋ` 계열 |
| 빛 | 보호, 관통, 시야 | `ㅗ`, `ㅛ`, `ㅘ`, `ㅚ` 계열 |
| 어둠 | 잠식, 약화, 침묵 | `ㅎ`, `ㅓ`, `ㅣ`, 특수 겹받침 계열 |

## 보스 등급별 속성 풀 운영 원칙

| 보스 등급 | 메인 속성 파편 | 보조 속성 파편 | 고유 재료 |
| :--- | :--- | :--- | :--- |
| 초반 보스 | 보통 | 낮음 | 하위 글자결, `돌: 새김` |
| 중반 보스 | 높음 | 낮음~보통 | `돌: 말문 조각`, `남김` |
| 상위 보스 | 높음 | 보통 | `돌: 말문`, `돋움`, 희귀 글자결 |
| 종결 보스 | 높음 | 낮음 | `돌: 깃듦 조각`, `지킴`, 상위 결 저확률 |

## 운영 체크 포인트
- 특정 속성 유저가 한 보스만 무한 반복해도 모든 재료가 해결되면 안 된다.
- 메인 속성 보스가 가장 효율적이되, 보조 속성 보스도 일부 가치가 있어야 한다.
- 후반으로 갈수록 보스 자체보다 `보스 + 특수 던전 + 근원의 나라`의 조합 루프가 중요해져야 한다.
