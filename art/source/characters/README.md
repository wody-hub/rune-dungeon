# 캐릭터 제작 원본

이 경로는 웹 클라이언트에 포함하지 않는 캐릭터 제작 원본을 보관한다. 런타임에 쓰는 최적화된 GLB는 `client/public/models/`에 둔다.

## 게이트 A 경로

- `concept/`: A1 방향 승인용 비교 이미지와 방향 메모
- `turnaround/`: A2 제작 시트용 기본형·전투형 턴어라운드, A 포즈, 대검, 색상·재질 시트

파일명은 `mvp-aram-<산출물>-vNN.<확장자>`로 쓴다. 이미지를 추가하거나 상태를 바꿀 때는 반드시 `docs/assets/characters.md`도 함께 갱신한다.

대화에서 생성된 이미지는 원본 파일이 이 경로에 저장되기 전까지 승인 입력으로 간주하지 않는다.
